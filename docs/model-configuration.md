# BI 模型配置中心

仅管理员可使用 `/api/admin/bi/model-config`。非管理员返回 404，所有响应禁止缓存与索引。供应商凭据由浏览器 RSA 加密后提交，服务端只返回新的不可变凭据引用，历史任务使用原引用。

## 私有管理连接

Naumi 和 Router 共用以下独立管理配置，值不得提交到 Git：

- `NAUMI_ROUTER_MANAGEMENT_TOKEN`：不少于 32 字符，独立于生成接口令牌。
- `MODEL_CONFIG_ENVELOPE_SECRET`：不少于 32 字符，与管理令牌、应用设置密钥分别设置。它用于两服务间加密传输凭据。
- Naumi 的 `NAUMI_ROUTER_MANAGEMENT_URL`：指向只允许应用访问的私有管理服务。
- `MODEL_CONFIG_TRUSTED_ORIGINS`：服务端允许的内网 origin，按逗号或空白分隔；两服务需一致。元数据服务始终拒绝。

Router 的监听、状态持久化及精确路径代理参见 Router 仓库的 `docs/model-management.md`。公网生成监听不会提供配置管理接口。发布需同时保留 PostgreSQL 模型/计费版本、应用设置密钥、Router 配置与执行状态和管理密钥。

## 版本和恢复

草稿按操作者隔离，保存要求原 revision。发布要求原 active version 和唯一操作 UUID；同一 UUID 重试必须携带原参数。发布依次准备版本组合、激活 Router、短事务切换 Naumi 指针并写审计。

断网或数据库提交不确定时，状态为 `unknown`，原 UUID 用于核对和恢复。此时不能另起发布绕过未决操作。准备阶段明确的协议/参数/货币成本校验失败会标记 `failed`，允许修正后建立新的发布。恢复历史配置创建新版本，保留操作者草稿，并要求发布原因。

首次初始化先在事务外只读发现现行配置，再在数据库锁内导入。现行 Router 供应商及候选以“待核验”配置导入，保留旧默认模型及原执行路径。能力未确认的池不会自动启用。只有管理员核验能力、引用有效计费成本并正式发布后，才切换为版本化混合路由。

## 计费与模拟

金额只由统一计费模块管理。模型表单只选择该模块的成本引用，提供币种、单位、来源说明，不创建第二套金额输入。模型版本和计费版本形成不可变执行组合；成本改动给新任务准备新组合，旧任务继续使用原组合。

最低成本策略要求所有适用的质量、尺寸、generate/edit 项都有明确且可比较的货币成本。积分不是供应商货币成本。美元有既定人民币折算率时使用整数微元向上取整，无折算率保留美元，不能混合比较美元与人民币。批量模拟与 Router 一致：按张成本乘数量，按任务成本计一次。

只读模拟不调用生成接口，也不预占容量。它展示规则和能力过滤结果，不保证供应商当时可用。历史可恢复版本的并发上限参与共享预算，实际账户容量取最严格值；提高新版本上限不一定立即提高有效容量。

## 管理 API

| 方法和路径 | 行为 |
| --- | --- |
| `GET /api/admin/bi/model-config` | 当前快照、当前操作者草稿、协议、用途和成本引用 |
| `PUT .../draft` | 校验并保存操作者草稿，要求 revision |
| `POST .../validate` | 校验已保存草稿、完整成本项，展示发布差异，无外部写入 |
| `POST .../simulate` | 图片能力/规则/货币排序模拟，支持数量 1–4 |
| `POST /api/admin/bi/model-config` | 以 UUID、revision、active version 发布 |
| `GET .../versions` | 发布状态与历史；`version` 可读取指定快照 |
| `POST .../versions` | 以新 UUID 恢复历史配置 |
| `POST .../credentials` | 保存浏览器加密的新凭据引用 |

执行接入与 BI 表单仍须按实施计划完成后整体验收和发布。仅管理接口通过测试不代表产品已经完成上线。
