# 画布底部 Dock 图标尺寸修复

## 问题

画布底部 Dock 的新增按钮使用 64×64 像素，并在超宽屏放大到 72×72 像素；其余操作按钮为 36×36 像素，导致新增图标和按钮在同一工具栏中明显过大。

## 实现

- 新增按钮调整为 44×44 像素，仍比普通按钮略突出，但不再破坏 Dock 的视觉平衡。
- 新增图标从 28/32 像素统一为 20×20 像素。
- 移除超宽屏自动放大规则，避免高分辨率桌面出现更严重的尺寸差异。
- 更新画布浏览器冒烟测试，校验新增按钮最多只比普通工具按钮大 12 像素，同时保持不小于 40×40 像素的点击区域。

## 验收标准

- 新增按钮在视觉上与 Link、框选、主题、生成、历史、快捷键和帮助图标处于同一尺寸体系。
- 新增按钮仍保留主色和轻微强调，不影响入口识别。
- 画布原有上传、节点尺寸和 Dock 操作保持正常。
