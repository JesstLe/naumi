## 重跑验证

准备专用测试数据库，禁止指向生产数据库。设置 `DATABASE_URL` 与 `NAUMI_VERIFY_ISOLATED_DB=1`，运行：

```text
npm run verify:product-fixes
npm run verify:video-postgres
```

启动本地应用（建议隔离端口 31089），应用和测试进程使用相同的测试数据库、媒体目录、至少 32 字符的 `SETTINGS_SECRET` 与 `VIDEO_WORKER_SECRET`。设置 `NAUMI_EDITION=cloud`、`NAUMI_MULTI_USER=1`、`OPENAI_IMAGE_MODEL=gpt-image-1`、占位测试 `OPENAI_API_KEY`，运行 `npm run verify:image-job-routes`。该脚本使用已经生成的本地测试产物，不调用收费图片供应商；同时创建独立测试账号和图片用于浏览器验收。脚本默认只允许 127.0.0.1。

浏览器验收截图保存于 `output/product-fixes-20261002/`，该目录不纳入源码提交。

## 发布与旧密钥迁移

发布前备份数据库与现有环境配置。强密钥保持原值；已有公开默认密钥须迁移，不能直接改 `.env` 导致已有 API Key、支付设置和用户自带接口密文失效。

停止应用和 Worker 后，在安装了项目依赖的源码目录中，以环境变量提供 `DATABASE_URL`、`OLD_SETTINGS_SECRET` 和至少 32 字符的随机 `NEW_SETTINGS_SECRET`，运行：

```text
node scripts/rotate-settings-secret.mjs
node scripts/rotate-settings-secret.mjs --apply
```

第一条只验证密文，第二条在同一事务内迁移设置和用户接口密文。若任何密文无法解密，整笔回滚；脚本不输出明文或密钥。成功后将部署 `SETTINGS_SECRET` 更新为新值，再启动应用和 Worker。旧登录会话随密钥更换失效，需要重新登录。另须为应用和 Worker 配置相同的独立随机 `VIDEO_WORKER_SECRET`。

任务恢复保留已持久化产物。进程被强制结束时，尚未返回或尚未写入检查点的同步供应商请求可能需要重试；应用积分结算仍幂等，供应商侧是否重复计费取决于其请求契约。没有执行真实供应商收费验证。无数据库的演示模式继续使用内存。
