# image2.5 输出参考价三倍售价表

## 需求与边界

2026-10-08：管理员要求先制作原生全部输出参考矩阵的售价表，按输出参考价×3定价，用于覆盖输入与综合成本。后台同样使用表格呈现。

与旧版的“完整 API 成本×1.5”是不同基数，本次不改旧预设的 factorBps，不把两个倍率叠加，不自动发布或修改用户扣费。未取得本次实测的逐任务输入成本证据，输入及综合成本覆盖是用户确定的定价策略，不在系统里伪装成已确认采购价。

## 已实现

- `/admin/billing/price-table`：管理员页面，45行规格，每质量分别列输出参考价、三倍售价。
- 黄金、铂金、钻石、网站官方价；原生Flare/Sunburst；分辨率、比例、质量筛选。
- 原生两模型共用15比例×3分辨率×5质量的225组合，四档900项价格；EXT不在此表。
- 每个输出价格重新以官网token×对应输出单价计算，与原调研JSON交叉验证，售价精确乘3。
- BigInt纳美元计算，保留原精度；人民币使用已发布预设的换算凭据，不读草稿、不猜汇率；积分只在最终舍入，组图不逐张先舍入再累计。
- 下载筛选后JSON明细；刷新真实读取后端，无localStorage定价。
- 管理导航增加“模型价格表”；供应商成本与高级配置保持原实现。
- 独立Markdown/JSON价格表，原始采购/能力调研JSON不修改。

## 接口

`GET /api/admin/billing/image25-prices`：现有requireAdmin校验，非管理员404；private/no-store响应。返回来源日期/链接、原生model、质量/会员档、固定倍率3、45行矩阵、已发布人民币换算快照（可为null）、`liveBillingChanged:false`。

没有写入接口、收费接口、数据库迁移或自动应用；报价表是持久版本化代码中的公开参考矩阵，不是新的独立账务系统。换算暂不可读时仍提供USD表并明确提示人民币不可算。

## 操作

管理中心→计费管理→模型价格表。选择实际原生model、会员参考档、规格和币种。每档右侧为三倍售价。高于medium的全档矩阵用于能力/价格参考，不改变现有medium上限，不能以请求max但执行medium多收费用。

人民币未核验不填0，USD三倍售价不是当前账号已确认人民币售价。售价减输出价不是完整利润。4K为模型档位，1:1为2880×2880。
