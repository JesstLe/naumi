# R2 与画布加载实施计划

已授权连续实施；以 `2026-10-13-r2-canvas-design.md` 为范围。

1. 集成：从origin/main建立独立codex/r2-canvas-103-20261013，合入agent-harness e89a1da/de8cae8和canvas审查648649a，保留四条历史回滚分支。记录103固定基线与锁；Cloudflare桶权限仅naumi对象读写。
2. `src/lib/storage.ts`：私有R2不要求public base，稳定key双写本地；签名GET/PUT、旧本地读取兜底。`src/lib/media-assets.ts`：独立PG资产表，sha256/驱动/所有权/变体状态，sharp受限像素一次生成，失败原图可读；授权由真实作品或显式直传owner判定。
3. `/media/[...path]`：权限先行、已登记远程对象短期签名重定向，旧本地仍读；变体缺失按单对象锁生成，返回私有缓存，禁止匿名经Next optimizer绕过。`/api/media/uploads`申请暂存签名与最终核验，作品入库引用不可变key。`cdnThumb`把受管图片转向稳定变体路由，公开demos继续原优化。
4. `src/components/canvas/canvas-image.tsx`：IntersectionObserver/ResizeObserver读取屏幕可见性与像素宽度，6并发共享队列、取消过期排队项、保持已成功缓存。ArtNode替换图片加载层，原尺寸上报/比例修复保持。
5. 画布两条上传路径接通直传客户端，旧local环境继续multipart；服务器对暂存对象验证实际大小、类型、sharp完整解码，正式key复制避免签名尚有效时覆盖；提交幂等、归属/父节点鉴权。
6. 聚焦验证：受限临时数据库+模拟S3验证认证/变体/直传/超限，真实R2字节/CORS/匿名拒绝；类型与固定Linux构建一次，按出现的新失败修复。最终独立代码审阅按executing-plans要求进行。
7. 刷新同事分支、固定SHA镜像，103最新备份与回滚（local副本及旧稳定key保持），脚本deploy-release.sh切换；原生账号历史/作品/Agent/模型配置不变，真实画布页面与下载验收，锁释放，维护计数3盘点清理，普通push/main整合。
