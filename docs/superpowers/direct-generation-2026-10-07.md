# 点击生成后直接提交

## 请求与实现

- 移除生图时「预计消耗／预占积分，是否继续」浏览器确认弹窗。点击生成本身作为用户发起该次操作，不再要求第二次点击。
- 共享 BillingProvider 的动态报价提交改为 `quoteAndSubmit`：先获取有效报价并校验版本，直接调用既有 submit。保留报价版本、积分与操作 ID 请求头，以及成功／失败／待核查重试状态处理。
- 画布统一 POST 分发和对话生图改用该入口；工具箱现有按已展示报价直接提交的入口保持不变。
- 清除画布「提交前确认报价」提示，扩图和文字修改按钮只保留操作名称。模型控件上的价格、工具箱价格展示保持不变。
- 不修改价格、服务端结算、余额校验、Agent 自主花费授权、删除确认或后台配置发布。
