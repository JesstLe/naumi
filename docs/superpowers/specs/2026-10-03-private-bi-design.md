# Naumi 内部 BI

用户把展示内容和实现细节交给开发者决定。本设计服务于运营人员核对用户、用量、积分和模型执行证据，不改变计费。

入口 `/admin/bi`，采用现有服务端管理员鉴权；未授权页面 404，所有数据、图片与更新接口独立鉴权，无公共导航入口、不被索引、响应禁止缓存。管理员后台可提供入口。

展示运营概览、个人/企业账户、业务任务、积分流水、作品与提示词、请求/执行模型、充值订单及后台访问记录。按北京时间自然日、账户类型、用户、关键词筛选，分页查询；账户详情支持继续查看该用户的所有数据。积分以已落账流水为准，预留与可用余额分开，作品数不用于估算消费。订单金额以人民币分转元，支付渠道 mock 单独列示，不计入实际收款。

目前没有企业身份与账户专属折扣事实来源。新增管理员登记资料：个人/企业/未登记、企业名称、约定实付比例和备注。约定折扣是运营资料，明确未接入扣费；当前实际计费为统一质量×尺寸价格。历史用户默认未登记，不根据邮箱、套餐名或充值加赠推断企业身份或折扣。

模型证据采用任务提交参数、持久付费操作记录和质量审计；请求模型、接口执行模型、质量回退分别展示。网关别名不能冒充实际供应商模型；通过已配置的 Router 只读操作接口查看真实路由尝试，失败或历史证据缺失时明确标记。只返回白名单字段，禁止返回任务原始 payload、API 密钥、供应商地址、密码哈希、支付密钥和执行缓存。

上线后新增模型调用审计：文本、视觉与图片的 OpenAI SDK 请求，以及兼容 HTTP 图片请求。记录账户、业务操作、稳定操作 ID、实际提交模型、上游返回模型、状态、响应耗时与可获取的 Token 数。每次调用尝试独立记录，不与积分结算等同；流式打开和 HTTP 响应不代表最终任务完成。审计失败不能重发请求或改变扣费，日志不保存原始请求响应、密钥或供应商地址。

作品缩略图通过管理员专用媒体接口读取已存储作品，限制体积并转换成图片，阻止任意 URL / 内网抓取与 SVG 执行。默认排除回收站作品，可单独筛选。任务失败、未知受理、回退、冻结报价与实际结算分开展示，不提供重发付费操作按钮。

实现顺序：数据查询与权限接口 → 独立 BI 界面 → 隔离数据库口径/鉴权/敏感字段/分页/媒体回归 → 浏览器验收 → 固定镜像发布与生产只读验收。新增资料表和访问日志表为可兼容增量；发布前备份，原生产配置、数据库和媒体保留。

界面使用淡灰工作区、白色数据表和海军蓝导航，蓝色表示筛选/操作，橙色表示核查状态；沿用 Geist 数字与系统中文。桌面固定内部导航、表格横向滚动，手机折叠为顶部导航；筛选、统计口径、空数据和分页清晰可见。每项指标提供来源和单位，所有没有证据的字段显示未记录。
