# AI Gateway 生图路由完善

用户于 2026-10-02 要求制定目标并解决此前审查发现的问题，授权继续实施及按根目录发布约定部署。

## 目标与边界

保留 `Naumi -> New API -> Naumi Router -> 图片供应商`。不修改 New API 大型分支，不自动切换未经验证的供应商，不把图片规格或估算成本当成真实账单。改动现有 Naumi 和独立 `JesstLe/naumi-router`，通过可复现的隔离测试验证。

## 持久化执行

每张图使用稳定的业务操作 ID，经 `extra_fields.naumi.operation_id` 传过 New API，JSON 与 multipart 均支持。Router 将规范化请求和参考图内容哈希绑定该 ID；不同内容重复使用 ID 返回冲突，相同内容并发执行只允许一个持有者。完成结果可重放，不能再次提交供应商。

Router 使用独立、权限受保护的 bbolt 文件保存执行状态、尝试记录、供应商任务 ID 和费用回执；提示词及参考图不落入执行账本。接受供应商任务之前保存尝试键，接受后立即保存任务 ID。APIMart 首次提交使用稳定幂等键；APIMart 和 fal 已知任务恢复只做轮询，未知是否受理时阻止新提交。未知结果使用不可自动重试的超时错误契约；状态变化和费用可通过内部鉴权接口查询。持久化不可用时失败关闭。

## 路由与运营

在既有能力筛选基础上加入明确的任务类别、参考图数和保真要求。每条路线支持按分辨率、质量、编辑模式匹配的整数微美元单张价格；不完整的价格矩阵不参与错误规格的选择，费用乘以图片数。保留旧固定价格配置的兼容，但标明估算来源。

运行时健康控制来自真实调用，不发付费探测；连续失败触发冷却、半开试探，按供应商限制并发。配置的禁用/不健康状态始终优先。加入普通 OpenAI Images 适配器，使供应商通过非秘密配置与环境变量凭据接入，默认不启用新供应商。

## Naumi 接入

对 Router 别名发送稳定每张操作 ID、请求分辨率及任务能力要求，覆盖生图、套图和 A+ 中可恢复的图片调用。对非幂等图片通道不盲目自动重试。原有积分结算与作品持久化保持业务语义，客户计费和供应商费用独立。

## 验收与发布

测试重复/并发请求、修改内容冲突、进程重开后结果重放、已受理恢复与未知受理禁止重复付费、持久化失败、能力筛选、请求估价、熔断与并发上限、multipart 扩展传递、费用记录和 Naumi 调用契约。使用本地假供应商，不调用收费模型。

发布前备份现有数据库、环境、媒体和 Router 状态，准备可检查的回滚，使用固定版本应用镜像和现有 `scripts/deploy-release.sh`。Router 独立服务使用固定提交构建产物并持久化 `/var/lib/naumi-gateway/router`。保持现有有效路由配置和凭据。服务器不可访问或无法安全切换时保留审查成果并明确报告；不声称已发布。
