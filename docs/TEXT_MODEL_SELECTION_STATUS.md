# 全局文字模型选择状态

更新日期：2026-09-23

## 范围

本轮统一覆盖会实际调用文字或视觉语言模型的入口：Agent、画布文字生成、画布逆向提示词、画布智能帮写、画布 OCR 兜底、全站 AI 帮写/智能优化、标题生成、一键套图规划、A+ 详情页规划、侵权检测、爆款复刻参考图分析、竞品工作台反推与 Agent 图片验收。

## 实现

- 新增 `/api/text-models`。接口优先从当前 OpenAI 兼容供应商 `/models` 发现模型；网关不支持模型目录时，回退到 `OPENAI_TEXT_MODEL(S)`、`AGENT_MODEL(S)`、视觉模型和默认模型配置。
- 新增全局 `TextModelProvider` 和复用型 `TextModelSelect`。选择结果在同一浏览器内跨页面保留；下拉列出已发现模型，并提供“自定义模型 ID”窗口。
- `authHeader()` 在原生账号和 Supabase 两种模式下都附带当前模型头，不再只在 Supabase 有访问令牌时生效。
- 服务端使用 `requestedTextModel()` 统一校验请求头，拒绝空白、超长或带异常字符的模型 ID；未通过校验时继续使用各功能原来的默认模型。
- Agent 的模型注册按 `baseURL + modelId` 缓存；空闲会话切换模型时重建 Agent 并使用前端提交的历史恢复上下文，运行中的会话保持当前实例直到本轮结束。

## UI

- 所有页面保持浅色工作台视觉；模型控件使用紧凑矩形按钮和矢量 `Cpu` 图标，不新增宣传文案。
- 全站 AI 帮写弹窗内置选择器，因此生图、印花提取、融合、局部重绘、试衣、变体、套图、A+、爆款复刻等共用帮写入口无需重复实现。
- 标题、套图、A+、侵权检测、爆款复刻、竞品工作台、Agent 和画布在主操作区额外提供可见选择器。

## 尚未做

- 本轮“自定义”指自定义模型 ID，复用站点已经配置的 OpenAI 兼容 Base URL 与密钥；没有新增第二套账号级文字供应商密钥管理页。
- `/models` 的能力标签在不同中转站不统一，目前只按模型名排除明显的图片、嵌入、音频、审核模型；最终兼容性由实际请求结果确认。
