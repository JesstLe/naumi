# 产品问题修复计划（2026-10-02）

范围：修复本次审查确认的六项问题，保留现有生图、套图、A+、视频与画布 API 的展示契约。

1. 账号权限：GET 在读取用户与作品之前授权；POST 将目标邮箱绑定到真实会话。验证匿名、跨用户、本人和管理员只读场景。
2. 会话密钥：集中校验 SETTINGS_SECRET，拒绝缺失及公开占位值；Compose 要求显式配置，安装器生成随机密钥，已有加密数据不自动换密钥。验证默认密钥不能签发/验证会话。
3. 下载边界：解析后检查 origin，仅允许相对媒体路径；外部来源逐跳校验协议、白名单、DNS 与私网地址，禁止隐式重定向。验证反斜杠、私网、协议和跳转攻击及合法下载。
4. 图片任务恢复：新增共享持久任务记录，保存输入、进度与产物检查点；数据库租约避免多实例重复执行，心跳防误回收；成功/失败积分结算幂等且可恢复。普通生图、套图、A+ 接入现有后台 Worker，保留 A+ 审核阶段，已完成图片不重复生成。验证跨进程读取、失去租约、重启恢复、审核与精确结算。
5. 画布一致性：撤销/重做保存检查响应，失败不更新本地与撤销栈；批量恢复/删除统一事务接口，位置/名称/尺寸/标记失败明确提示。验证 HTTP 错误、网络错误、成功及混合节点操作。
6. 访客画布：区分认证准备与未登录，取消弹窗后显示登录/首页入口。验证登录弹窗关闭、重开及已有账号正常进入。

执行顺序：1/2/3 → 4 → 5/6 → 类型检查、lint、生产构建、数据库故障注入与浏览器回归。

交付：实现、可重复运行的回归脚本和修复记录。上线密钥迁移与发布按真实部署配置核验；不会自动替换既有 SETTINGS_SECRET 而破坏已加密配置。
