# 无限画布 Photoshop 式工具栏（2026-09-29）

## 目标

- 保留底部横向位置，将 Dock 升级为分组清晰的专业工具栏。
- 参考 Adobe Photoshop 的工具组织方式，不复制其品牌资产。
- 工具栏使用浅色工作台表面、方形小圆角按钮和向上飞出菜单。
- 节点生成 Dock、批量操作栏和小地图必须避开底部工具栏安全区。

## 已实现工具

### 操作模式

- 移动工具：默认模式，快捷键 `V`。
- 框选工具：拖拽框选多个节点，快捷键 `M`。
- 抓手工具：禁止节点拖动，拖动画布进行浏览，快捷键 `H`。

### 创建工具

- 添加节点：打开文字、图片节点、上传图片和生成历史飞出菜单。
- 文字节点：直接在视口中心创建文字节点。
- 图片节点：直接创建空白图片生成节点。
- 上传图片：直接打开文件选择器并落到视口中心。

### 生成与资源

- 生成衍生图。
- 打开生成历史。
- 显示连线操作提示。

### 更多工具

- 整理画布。
- 小地图开关。
- 网格吸附开关。
- 适应视图。
- 深浅画布底色切换。
- 快捷键与帮助。

## 响应式与兼容

- 桌面端工具栏在画布底部水平居中，更多工具与创建菜单向上展开。
- 390px 窄屏使用更紧凑的按钮尺寸，工具栏位于视图控制条上方且不越界。
- 节点 Dock、小地图和批量操作栏在窄屏预留 `128px` 底部安全区，桌面端预留 `84px`，避免覆盖工具栏。
- macOS 与 Windows 共用 `V/M/H` 无修饰键切换；输入框、弹窗和菜单打开时不接管键盘。
