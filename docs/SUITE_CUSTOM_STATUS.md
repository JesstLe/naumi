# 一键套图自定义配置状态

更新时间：2026-09-14

## 已实现

- “自定义配置”已从禁用占位改为可用功能。
- 默认提供 5 张可编辑结构，并支持 1-20 张自由增删。
- 每张图可独立配置：主图 / 副图 / 详情、图片标题、内容或版式要求。
- 支持 1:1、3:4、4:3、16:9、9:16 五种画幅。
- 支持上下调整生成顺序；自定义结果按该顺序展示。
- 前端实时显示主图、副图、详情数量与预计积分。
- 后端严格按自定义清单规划和生成，不再写死 13 张；智能匹配模式仍保持 1 主图 + 4 副图 + 8 详情。
- Agent `generate_suite` 已支持 `structure=custom` 与 `shots`，积分预检按实际张数计算。

## 同模块审计与修复

- 前后端上传上限统一为 4 张，并补充 PNG/JPG/WebP 类型校验。
- 任务轮询增加登录凭证和任务归属校验，防止跨用户读取生成进度。
- 部分图片失败时仅按成功张数扣费；全部失败时完整退款。
- 积分 reservation 写入失败时立即退款并清理任务，避免余额长期占用。
- 工具中心“一键套图”费用从错误的 20 修正为智能模式实际费用 78。
- Agent 平台枚举与页面实际平台统一为淘宝、抖音、拼多多、小红书、亚马逊和跨境独立站。
- 多张产品参考图会先拼成单张白底联系表再发送，兼容只接受单文件 `image` 的 OpenAI 兼容接口。
- 图像编辑请求改为标准 multipart HTTP 调用，避免部分中转对 OpenAI SDK 上传格式的兼容问题。
- 上游忽略画幅并返回方图时，服务端会无裁切补足目标比例；普通图片使用同图柔化延展背景，亚马逊白底主图使用纯白补边。
- 仅对限流、服务端错误和网络超时重试；403/参数错误等确定性失败不再无意义重复请求。
