# 管理员用户用量管理

## 已完成

- 管理后台新增「用户用量」Pro 板块，支持 7 / 30 / 90 / 365 天切换。
- 汇总实际结算的积分扣费：消耗积分、收费操作次数、活跃用户数。
- 按用户展示消耗积分、操作次数、剩余积分、最近使用时间，并可直接打开用户明细。
- 增加每日消耗趋势条，默认展示最近 14 个有记录日期。
- 新增 `GET /api/admin/usage?days=N`，复用管理员鉴权、数据库开关和 Pro 门控。
- 数据来自 `app_ledger` 的负向 `consume` 结算流水；`管理员调整积分` 不计入用户用量。

## 还未完成

- 当前没有导出 CSV/Excel 功能。
- 当前用量按积分和操作次数统计，尚未拆分到模型、工具或成本金额维度。
- 当前余额调整仍在「用户与会员」板块完成，用户用量板块提供跳转入口。

## 验证

- 基线构建：`npm run build`，exit 0。
- 修改后构建：`npm run build`，exit 0；Next.js 产物包含 `/api/admin/usage`，`/admin` 首屏构建成功。
- 差异检查：`git diff --check`，exit 0。
