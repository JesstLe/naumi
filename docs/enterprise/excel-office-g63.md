# G63 日常办公级在线表格编辑

## 用户目标与选型

用户要求员工实际在团队排期附件上日常操作，交互需贴近Excel。G62的稀疏单元格编辑不是完整电子表格引擎。本模块采用ONLYOFFICE Docs完整Spreadsheet Editor，不继续手写网格模拟Office。与Microsoft Excel桌面版不宣称100%等价；通过公司真实图文工作簿逐项验收。暂不接公有云编辑服务。

官方资料现场核验：Docs API basic-concepts、config、callback-handler、command-service/forcesave和Docker-DocumentServer README。官方推荐RAM4GB+、双核2GHz+；因此不直接将新进程塞到47的4核8GiB内。先本机独立服务验证，生产需独立容量方案及原企业激活门禁。固定镜像版本/摘要、JWT鉴权；开源版授权/并发限制不按商业OEM版推断。

## 产品行为

1. 团队排期Excel附件保持原入口；轻量预览旁增加在线编辑，使用大工作台。在线编辑器提供中文浅色Ribbon、真实单元格就地编辑、框选、多格复制/粘贴、行列与格式工具、公式栏和多工作表。
2. Office显示文档有改动与Naumi落库是两个状态；只在保存回调、文件验证、事务/CAS/审计全部成功后显示已保存到系统。保存失败不清空文档。
3. Ctrl+S/保存触发Office forcesave；关闭前等待/提示系统保存状态。保存成功后关联新二进制工作副本，原来源Excel不覆盖。再打开取最新工作副本。
4. 有G62修改清单时先叠加后交给Office，避免旧修改丢失。旧XLS由Office编辑并保存为XLSX，原文件保留。宏文件暂不纳入常规编辑入口，不静默剥离宏。
5. 多窗口同附件先采用保守独立会话+CAS；冲突保留已编辑文件供恢复，不宣称多人实时同格协作已验收。

## 集成与存储

本机适配器仅访问127.0.0.1 PostgreSQL及本机来源blob；现有正式员工鉴权不由local-owner替代，生产默认关闭。Office API配置、原文件下载和保存回调使用随机会话票据、JWT、有效期与固定来源校验；回调下载只接收固定DocumentServer origin及文件路径，禁止重定向。文件大小64MiB、ZIP条目/展开上限检查；普通附件4MiB上传限制保持。

保存专用方法复用SourceWorksheetStore权限事务与同一apply/CAS/幂等逻辑，在一次事务中写文件、替换精确附件引用和审计。失败全部回滚，不留下已关联但缺文件的状态。会话恢复材料保留在忽略目录，令牌不入Git或日志。

## 验收矩阵

- UI：中文浅色、Ribbon/公式栏/Sheet页签，1500px桌面、全屏、移动端阅读。
- 操作：键盘就地输入，方向键/Enter/Tab，范围选择、复制粘贴、格式、行列、公式实时重算、多Sheet。
- 文件：真实图文XLSX、多Sheet及大文件；保存/关闭/重开、新值/公式与图片存在；原文件hash不变。
- 存储：权限撤销、跨企业、CAS冲突、重复回调、回调JWT错误、URL越界、超限、损坏ZIP、失败原子性。
- 回归：G62轻编辑/预览、G60滚动、G59任务中心；生产47连接和写入均为0。
