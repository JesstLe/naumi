# G19 需求与任务的来源参考资料

## 缺口与产品路径

原表管理员能查看附件，但源行转需求后只有文字溯源；普通执行人员不应被授予全企业原表权限才能看参考图。本模块将用户明确选中的本行附件作为需求级只读参考资料，显示于原需求详情和任务详情。

管理员在“由来源建立需求草稿”时逐个勾选参考文件（默认不选，最多50个）；提交时冻结ID、名称、内容SHA256、字节、类型及源行指纹。已有需求没有选择快照时保持空，不自动回填或扩展父行/子行/同名行的资料。原文件不复制为交付文件，不改变源数据、身份、任务状态或绩效。

## 授权

- 选择时仍须request+manage+目录管理员（本机准备模式为明确local-owner），且所选文件必须属于该源行。
- 阅读时逐事务复核当前企业、团队、账号及现有canRead需求权限；不要求执行人员拥有目录管理员权限，也不给他们整表浏览权。
- 查询参数只接受orderId与选中文件ID，不接受调用者指定的源批次/行号。跨需求、跨企业、非成员和未授权账号均拒绝。
- 原批次停用、源行原文/资产元数据变化、文件缺失/损坏、身份撤销都阻止新文件读取。元数据列表显示不可用原因；已下载文件不宣称可远程撤回。
- 单个文件在同一描述符上核验大小和SHA后，再次鉴权才发送。PNG/JPEG按真实签名预览；其他文件下载，禁止HTML/SVG内联。no-store/nosniff/sandbox保留。

## 数据与兼容

source.sourceAssetIds为可选字段。老请求省略此字段时保持原幂等指纹，不因为新版本补默认值而拒绝旧重放。新选择写入既有order_sources.snapshot.referenceAssets/referenceRowHash，不新增业务数据库结构。

参考资料属于整个需求，沿用既有需求可读范围（含有效请求侧、执行侧、历史参与者及可认领人员）；不声称按单任务附件隔离。交付上传/验收仍走原delivery_assets，参考文件ID不能用于伪造已完成交付。

## UI

原来源转草稿表单显示本行文件复选框与选择数量；原需求/任务详情增加“来源参考资料”，展示按需图片预览、文件名、大小、原SHA和受保护下载。预览使用受保护原图的缩放显示，不生成新的缩略图；每次只加载一张。PNG/JPEG限8 MiB、单边8192像素、总计1600万像素，JPEG尺寸只在前64 KiB中解析；超限或未识别尺寸时保留原文件下载。原有编辑、提交、任务动作和交付区保持。切号/切团队/关闭详情丢弃旧请求；页面重新聚焦时重新检查资料可用性。

独立PG覆盖明确选择、空/老快照、错误源行/兄弟附件、重复ID、选中元数据及幂等、普通执行人可读而整表403、跨企业/团队/账号、撤权、原批次停用、原文/元数据/文件损坏、原文件字节和非交付语义。BFF和原UI验证完整选择→草稿→分配执行→查看参考文件链路；真实库不创建演示任务或真实引用。
