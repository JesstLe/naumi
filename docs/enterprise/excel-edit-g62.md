# G62 Excel工作副本编辑与大尺寸阅读

## 方案决定

原始Excel继续作为来源证据。使用不可变原文件 + 稀疏单元格修改清单 + 附件引用版本，不在服务器重新转换36MiB图文文件，不使用SheetJS整本重写丢弃drawing/图片。修改清单存入既有source_worksheet_files，附件引用增加可选excelRevision，保存沿用worksheet-command的权限/版本CAS/幂等/审计；不新增数据库迁移，不放宽原4MiB上传限制。普通预览和原始下载保持，重新打开按清单复现编辑。

XLSX导出在浏览器后台线程中按行/单元格定点修改原ZIP的worksheet XML，保留原媒体与其他对象字节；公式缓存失效并标记Excel打开重算，不冒充完整公式计算引擎。旧XLS可保存系统内编辑副本，保留图文原文件；本轮不以转换丢图的XLSX替代原生XLS。

交互增加编辑模式、双击/公式栏输入、文本/数字/公式/清空、撤销重做、保存版本、未保存退出确认；只保存明确选择的附件单元格，不修改其他行的同名文件。保存失败/并发冲突保留输入。

查看区域提供全屏、适应宽度、25%至200%缩放及图片式Excel图文视图，图文默认适配容器，不再在手机上只显示半张图；表格/编辑视图保留原行列定位。每次编辑/缩放不跳回顶部。

### 明确边界

这是附件单元格工作副本，不是完整Office协同排版编辑器；暂不含多人实时同格编辑、插入删除工作表/行列、复杂图表或图片内文字编辑。XLS系统内保存编辑副本，导出保持原文件；XLSX按原ZIP定点修改XML导出，XLSM代码路径保留包内对象但未以真实宏工作簿验收。公式不在网页内执行，有编辑后显示待Excel重算；导出清理缓存并请求本地Excel完整重算。共享公式超出解析范围时提示而不静默损坏。
