## 4. 完成边界和已知差异

本轮为本地可交互原型增量及可运行只读预演CLI。当前预演接JSON，不在浏览器内解析1.3GB压缩包。CLI只接受单工作表主xlsx，多工作表明确拒绝，不悄悄只读第一张；不解压任意路径、不修改源文件。原始资料仅生成本地忽略产物。

界面没有正式导入按钮；对真实365行范围的预演不等于同步钉钉、创建员工任务或完成正式附件迁移。所有真实账号ID、上传时间和日期语义保持待确认。筛选和填色是自建规则，不猜源隐藏配置。

原型基于原生表格，小规模验证；生产Grid/许可/万行性能尚未验收。每视图草稿只保存配置，表级字段和标签选项独立操作。看板日期明确显示“承诺”，不是原截图未确认日期。条件按第一条匹配，列预设色与行规则同时可用。
