# G58 PRD：团队排期可编辑工作表

日期：2026-10-19。需求依据：用户提供的团队排期截图，以及“顶栏筛选、排序；产品图点开；所有表格空支持增删改查”。本模块在原18482产品上实施，47线上保持原状。

## 1. 范围与数据定义

- 总表、设计人员分组、需求方分组、排期看板共享一份工作表，不复制四套业务数据。
- `import_batches/import_rows/import_assets` 是原始来源证据。编辑不修改这些表、原Excel/ZIP或原文件。
- `source_worksheets` 是可编辑工作副本。首次只读查询返回v0投影，不写数据库；第一次成功编辑原子建立v1。
- 工作表中的“完成情况”是日常表格内容，不等于正式任务验收。编辑不生成orders/events、积分或绩效事实。
- 来源姓名继续作为文本，变更“设计师”文本不创建账号，不确认花名映射，不分配正式执行权限。
- 实施采用本机独立数据库副本。原库及原文件保留，新增操作只进入副本；生产接入仍遵守既有身份、资源、事件结案和蓝绿条件。

## 2. 页面交互

### 顶部工具栏

搜索支持任意单元格文本及附件名称；输入后回到第1页。筛选支持任意未删除字段，可叠加多个条件：包含、等于、为空、不为空。每个条件显示可移除标签，清除条件重置搜索/筛选/排序。

排序支持任意字段升序/降序，数字字段按数字，文本含数字按自然顺序；空值在两种方向均置后。同级相同值保持原顺序。总表保留父子层级，对同级排序，不将子任务拆成独立父任务。筛选子项时保留父上下文并标识。

每个列头打开该列的筛选、升序、降序、字段设置。顶部保留全局“筛选”“排序”“字段”“修改记录”“回收站”；新增记录在右上方。

### 单元格

- 单击文字或空白内容打开对应编辑器；文本支持换行，日期用日期输入，数字按有限数字校验。
- 保存写入服务端；取消不写。清空是保存空字符串，不删除整行。附件空值是空数组。
- 单元格已有源内容先展示原值，源日期/数量不被自动重算。源“数量”保留文本单位和估计标记；新增数字字段才执行数字校验。
- 多窗口冲突返回409，保留当前输入并提示刷新；不静默覆盖另一窗口。

### 行

新增记录支持所有非附件字段及可选父任务；图片/附件在新增后管理。新增顶层行优先显示。行操作提供整行编辑、新增子项、原始来源查看、删除。

删除为软删除，进入回收站；原来源不删，子项保留、父项删除期间单独显示，恢复父项后重现关联。新增父关系明确确认并校验循环；导入的唯一候选关系仍标注候选，不冒充已确认关系。

### 列

字段可新增、读取、改名、调整宽度100–420px、显示/隐藏、删除和恢复。支持文本、日期、数字、图片、附件；名称列固定保留。字段类型建立后冻结，避免已有数据被静默转型；删除字段保留单元格值，恢复后原值重现。最多64字段。

### 产品图及附件

产品缩略图单击打开大图抽屉，支持多图切换、下载原图及进入管理。空格显示添加入口。管理支持本地上传、选择已有来源文件、移除当前工作表关联；保存前的选择可取消。

PNG/JPEG经实际解码验证，单文件≤4MiB、≤1600万像素；其他附件只以下载方式提供。每格最多50文件。文件按SHA256存储和校验；相同内容去重。每来源批次上限1000上传文件/128MiB，达到限制时显示失败且保留已存记录。移除关联不擦除原文件或历史记录。

## 3. 持久化、并发与审计

工作表主键为企业ID+来源hash，文档含列、行、源行引用、父项及删除状态。新增行用UUID，导入行用稳定e+Excel行号；不以可编辑标题识别行。

所有写命令携带commandId、expectedVersion。事务内重新鉴权、确认来源active、获取命令及工作表锁、校验版本、更新文档、写审计和幂等回执；任一步失败整体回滚。相同命令原样重放返回旧结果，改内容或身份重放拒绝。

审计记录操作人、时间、版本、操作类型及前后值；每页30条，按版本向前分页。文档最多10000行、12MiB。用户切换企业/团队时清除工作表缓存并拒绝旧作用域回写。

## 4. 接口与权限

同一SourceWorksheetStore供本机准备适配器及正式员工适配器调用，不建立客户代码分叉。

|操作|本机API action|正式运行时路径|
|---|---|---|
|读取工作表|worksheet|GET /v1/imports/worksheet|
|写命令|worksheet-command|POST /v1/imports/worksheet-command|
|审计|worksheet-audit|GET /v1/imports/worksheet-audit|
|上传|worksheet-upload|POST /v1/imports/worksheet-upload|
|取上传文件|worksheet-file|GET /v1/imports/worksheet-file|

本机仅回环监听、项目会话、同源/CSRF及服务端token；正式BFF沿用Naumi会话与短时签名身份，运行时重新验证enterprise/team/subject、manage权限及启用的来源目录管理员资格。不因为点击页面按钮或输入姓名就扩权。源停用、撤权、外企业、匿名、非法字段、越界文件引用均拒绝。

上传接口有独立6MiB JSON体上限；其他命令128KiB。文件响应不缓存、禁止嗅探，非图片强制下载；不把本地文件路径或连接秘密返回UI。

## 5. 验收矩阵

1. 364来源行、292附件进入独立副本后原文和原库hash一致；原ZIP hash保持。
2. 空值填写、现值修改、清空、整行编辑、新增行/子项及删除恢复可跨刷新保存。
3. 任意列筛选/排序；中文自然排序、数字排序、空值置后、过滤保留父上下文。
4. 自定义五种字段、字段改名/宽度/隐藏/删除恢复；名称列保护和类型冻结。
5. 原产品图点开、上传图片/附件、原图下载、移除关联；非法图片/路径/文件跨域引用拒绝。
6. CAS竞争只有一方成功，重复命令幂等，拒绝失败不改变版本和数据。
7. 正式管理权限、跨企业隔离、目录撤权和匿名验证；工作表编辑不产生正式流程事实。
8. 原有完整产品模块保留，桌面/390px表格滚动受容器约束，页面无JS异常。

## 6. 明确后续

本模块是工作表编辑，不是把Excel历史改成正式验收。正式需求的转入、人员绑定、受理/分配/执行/独立验收仍走既有流程。目标47的正式迁移、员工开通、容量验收和发布尚未执行。暂未加入多单元格粘贴、公式计算、跨表关联公式、多人实时光标；它们不被伪装成已实现的能力。
