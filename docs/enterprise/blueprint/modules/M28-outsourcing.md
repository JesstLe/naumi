# M28 外包、供应商协作、交付权利与验收结算

服务域：工作流+资产+成本｜阶段：P3按需｜上游：D08、D09、D10、D14｜依赖：M02、M13、M17、M25

## 1. 使用场景与责任
大促峰值或特殊视频/摄影任务交给外部团队。业务主管负责范围与验收，采购/法务核合同和权利，财务核结算；外包不成为能遍历全公司资产的普通成员。

## 2. 功能与页面
- 外部协作方、合同/保密与授权证明、受限任务邀请、交付版本、验收与结算申请。
- 外包仅看指定任务、必要商品资料及授权素材；邀请有期限，可撤销。
- 内部运营/设计主管仍承担业务责任，外部交付需内部验收和素材授权确认。
- 外包与员工绩效分开统计，供应商报价不向普通员工公开。

## 3. 数据获取与关键字段
| 字段 | 类型及规则 | 来源 |
| --- | --- | --- |
| vendorId / engagementId | 供应商与单次合作关系 | 采购确认 |
| contractRef / confidentialityRef / rightsRef | 受限合同证据和使用权 | 采购/法务 |
| externalIdentityId / expiresAt / scopes | 独立邀请身份和最小范围 | M02 |
| taskId / internalOwnerId / deliverables | 任务责任与交付范围 | M08 |
| quotation / currency / budgetApprovalId | 费用与审批；限定财务读取 | M25 |
| acceptanceId / settlementRequestId | 验收证据到结算申请的引用 | M17/财务 |

## 4. 流程与状态
`合作申请 → 合同/权限确认 → 邀请 → 执行 → 内部验收 → 结算申请 → 归档`。
合作结束撤销身份与新下载能力，保留可用权利和交付证据；撤销不删除已获使用权的必要资料。结算成功需财务系统真实回执，不以验收自动标已付款。

## 5. 跨模块联动
M09评估产能溢出，M10由主管选择外包路径，M13隔离文件，M14核验权利，M17终审，M25归集合同成本，M29记录外部访问，M19发送受限通知。

## 6. 权限与规则
禁外包账号继承内部组织树或共享任务池；导出、源文件和原始商品资料按必要性开放。禁止合同到期自动续权；受限链接失效窗口按签名TTL说明。

## 7. 接口与事件（拟定）
`POST /api/enterprise/v2/vendor-engagements`；`POST .../{id}/invitations`；`POST .../{id}/settlement-requests`。
产生 `vendor.engagement.closed.v1`，M02撤权、M25更新待结算；对外付款不是本服务直接执行的副作用。

## 8. 异常与验收
- 邀请转发/过期/猜ID不能看其他任务；合同缺权利证明阻止对外发布。
- 外包退出后未结任务有内部接管人，不丢源文件。
- 同一验收重复申请不重复结算；财务回执未知进入核查。
- 源文件和商用授权交付不全时不能按完整交付结项。

## 9. 实现边界
是否有外包、采购系统、结算口径尚未确认；本模块按可选能力设计，不强加到第一期员工任务链。

## 10. 开发工作包（本模块实施清单）
- **M28-W01** 数据：建立外部engagement/合同权利/限期身份/内部责任人与结算申请去重键。
- **M28-W02** 后端：实现任务最小范围邀请、撤权和内部终审，结算仅申请不直接付款。
- **M28-W03** 前端：实现受限供应商交付页、合同资料/源文件清单与验收结算状态。
- **M28-W04** 验收：邀请转发/过期不可越权、缺版权拒发布、重复申请不多结算。
