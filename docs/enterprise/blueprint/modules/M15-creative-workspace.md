# M15 任务创作工作区、Naumi画布与AI执行关联

服务域：资产创作｜阶段：P1｜上游：D08、D09、D10、D11｜依赖：M10、M13、M14

## 1. 使用场景与责任
员工从业务任务直接进入已有Naumi画布/创作工具，携带商品素材与规格；完成后选择交付稿回到任务。业务任务与AI生成作业分开建模，避免一次生成失败让业务工单失败。

## 2. 功能与页面
- “进入制作”创建/打开关联工作区；展示冻结brief、规范、输入素材和交付清单。
- 生成、手工设计、外部软件上传三条路径都能完成任务，不强制所有员工用AI。
- 支持把图片/源文件/视频保存为候选版本；明确“保存草稿”和“提交评审”两个动作。
- 工作区可列关联创作作业状态，不向普通企业角色显示供应商密钥或采购成本。

## 3. 数据获取与关键字段
| 字段 | 类型及规则 | 来源 |
| --- | --- | --- |
| businessTaskId / workspaceId | 一对多关联，业务ID不复用创作ID | M10+现有画布 |
| executionJobId / providerOperationId | 已接受作业的稳定引用 | 现有执行服务 |
| inputRevisionIds / guidelineVersion | 可授权的冻结输入 | M13/M14 |
| outputRevisionIds / provenance | 输出与派生来源 | D09 |
| commandId / acceptanceState | 提交幂等和供应商接受状态 | 执行服务 |
| billingOperationId / chargeStatus | 计费引用，不复制最终账本 | D11 |

## 4. 流程与状态
工作区 `未创建 → 可编辑 → 保存候选 → 已提交`；创作作业独立有queued/running/succeeded/failed/unknown状态。
业务重试只恢复关联/查询已有作业，不重复创建已接受或unknown的付费请求。输出已保存不代表交付已验收。

## 5. 跨模块联动
M11记录制作进度；M13保存私有资产与来源；M16选择固定版本评审；M17冻结交付；M25读取计费事实；M20提供受控SOP/Skill建议，不绕过业务权限。

## 6. 权限与规则
工作区授权由任务范围派生；协作者显式授予，不能通过分享画布链接读取全企业资料。业务主管无权查看用户所有对话/底层模型调用；企业内容边界沿既有约定保留。
任何自动化执行在付费/外部发布前有明确操作主体及权限，不能由导入历史记录触发。

## 7. 接口与事件（拟定）
`POST /api/enterprise/v2/tasks/{id}/workspaces:link`；`POST .../tasks/{id}/delivery-candidates`；执行仍调用现有持久作业API。
产生 `creative.output.linked.v1`，M13/M16消费；消费现有创作状态适配后的事件，不把供应商原始回调直接当工单命令。

## 8. 异常与验收
- 关闭页面/重连可恢复原执行作业；unknown作业只查询、不自动重提付费。
- 工作区误关联别家公司任务拒绝；已交付文件不可被后续编辑覆盖。
- 外部软件上传能走完整评审，不依赖AI次数；原生画布用户不受新任务接入影响。
- 交付候选只取成功且可用资产；生成成功但存储失败不能伪报可交付。

## 9. 实现边界
Naumi画布、媒体、持久执行/计费已有代码；尚无企业业务工单到这些资源的生产适配。4核8GB上不运行本地大模型；媒体转码/重型处理独立限流worker或后续拆机。

## 10. 开发工作包（本模块实施清单）
- **M15-W01** 数据：建立业务task到workspace/executionJob/assetRevision/billingOperation的稳定引用。
- **M15-W02** 后端：实现受控工作区关联与候选稿提交，接受/unknown执行仅恢复查询不重建。
- **M15-W03** 前端：从任务进入Naumi或上传外部制作，区分保存候选、提交评审与作业状态。
- **M15-W04** 验收：断页重连原作业、输出成功存储失败、外部制作路径和创作既有用户无回归。
