# M26 钉钉、聚水潭及其他系统连接器与数据导入

服务域：集成worker｜阶段：P1人工导入+钉钉身份、P2聚水潭｜上游：D01—D06、D12—D14｜依赖：M01、M02

## 1. 使用场景与责任
公司已经使用钉钉和聚水潭，另有未盘点系统；IT负责应用授权和令牌，数据负责人确认字段，业务确认映射。不是一次把所有系统全部打通，先接必要数据。

## 2. 功能与页面
- 连接器登记、可用权限检测、字段样本、映射修订、导入预览/批准、同步状态、异常队列和逐行对账。
- 钉钉优先组织身份/消息，需求改在本系统写；不默认继续双向同步两套需求表。
- 聚水潭优先店铺、商品、SKU；订单/售后仅在M27确需时取聚合业务指标，不导入买家个人资料。
- 手工CSV为受控兜底：模板、编码/类型校验、预览、批次ID和失败行下载。

## 3. 数据获取与关键字段
| 字段 | 类型及规则 | 来源 |
| --- | --- | --- |
| connectorId / system / tenantKey | 系统租户+环境，测试/正式分开 | IT登记 |
| grantedScopes / capabilities / expiresAt | 实际探测能力，不按产品名猜 | 授权接口证据 |
| mappingVersion / sourcePriority | 字段映射、人工优先规则 | 数据负责人 |
| cursor / watermark / overlapWindow | 增量游标和补拉水位 | 同步任务 |
| sourceRecordId / sourceUpdatedAt / tombstone | 外部事实与删除语义 | API/导入 |
| importBatchId / rowDigest / status | 批次、原行hash、校验结论 | 导入工具 |

## 4. 流程与状态
`登记 → 授权验证 → 样本映射 → 预演 → 批准 → 增量同步 → 定期全量对账`。状态含paused/rate_limited/expired/degraded。
增量分页失败保留上一已确认游标；时间重叠窗口按来源ID+修订去重。源端无完整删除语义时不得因少一页就删本地资料。

## 5. 跨模块联动
组织写M01、主数据写M03、历史需求写M06、发布结果写M18、经营指标写M27、成本写M25。连接器只经域命令/导入接口提交，不跨服务直写业务表。

## 6. 权限与规则
令牌只在秘密库，页面仅显示指纹/到期；最小授权，不在日志输出响应中的凭据/个人信息。导入不会触发付费创作、上架或历史通知群发；外部写入需独立授权和预览。

## 7. 接口与事件（拟定）
`POST /api/enterprise/v2/connectors/{id}:probe`；`POST .../imports:preview`；`POST .../imports/{id}:apply`。
产生 `integration.batch.applied.v1` / `integration.sync.failed.v1`。外部Webhook验证签名、时效、防重放；回调只入收件箱，再异步更新域。

## 8. 异常与验收
- 限流尊重Retry-After，指数退避+抖动；不高频重刷挤占平台额度。
- 令牌过期/部分权限不足时明确缺哪些字段；失败记录可重试但不重复业务副作用。
- 审核导入可按批次做补偿修订，不删除已被任务引用的主数据。
- 两次导入/重复回调无重复数据，游标断点重启能继续，人工维护不被覆盖。

## 9. 实现边界
系统名称已确认，API文档/付费范围/限流/测试租户尚未确认。详见D01—D14来源清单；其他系统先登记责任人，不编造现成接口。

## 10. 开发工作包（本模块实施清单）
- **M26-W01** 数据：登记每连接器tenant/scopes/能力证据/映射修订/水位/来源ID与批次。
- **M26-W02** 后端：实现样本probe、preview/apply、分页增量/重叠去重/退避/验签inbox和逐行回执。
- **M26-W03** 前端：实现权限缺口、映射差异、失败行、暂停恢复和待人工确认队列。
- **M26-W04** 验收：重复导入/回调、断点恢复、源删除语义、权限收回不清空本地。
