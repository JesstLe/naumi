# M13 素材、源文件、版本、权限与复用

服务域：资产创作｜阶段：P1｜上游：D04、D09、D10｜依赖：M02、M03

## 1. 使用场景与责任
运营提供商品原图，设计提交源文件和预览，美工复用已批准视觉；资产管理员处理重复、授权到期和归档。不让员工通过聊天反复传散落文件。

## 2. 功能与页面
- 需求附件、团队素材库、商品素材、个人草稿、已批准品牌资产与交付版本。
- 大文件直传、可恢复上传、预览/缩略图异步生成、源文件下载、版本差异和引用位置。
- 支持图片、设计源文件及视频；首批格式/单文件限制先由真实样本决定，策略可配置。
- 内容hash辅助去重，但权限和引用独立，不能因为相同hash就跨企业共享。

## 3. 数据获取与关键字段
| 字段 | 类型及规则 | 来源 |
| --- | --- | --- |
| assetId / revisionId / objectKey | 稳定ID、不可变版本及私有存储引用 | 存储适配器 |
| enterpriseId / ownerScope / classification | 租户/品牌/店铺与敏感级别 | M02+提交上下文 |
| sha256 / bytes / mime / dimensions | 服务端校验，不信任文件扩展名 | 上传结果 |
| provenance / sourceRevisionIds | 上传/创作/派生来源与父版本 | D09/M15 |
| rightsRecordId / expiresAt | 使用权与到期 | M14/人工证明 |
| usages / retentionPolicyId | 被哪些需求、任务、发布引用 | M06/M17/M18 |

## 4. 流程与状态
`待上传 → 上传完成 → 校验/扫描 → 处理中 → 可用/隔离 → 归档`。只有可用的revision能提交或发布。覆盖上传必须创建新revision；已验收交付指向旧版本不漂移。

## 5. 跨模块联动
M06读取需求附件；M14检查商标/版权；M15创作输入输出留来源；M16评审固定稿件；M17冻结交付包；M18只使用批准版本；M29按引用和保存策略处理删除。

## 6. 权限与规则
私有存储，短时签名URL；服务端核验tenant、任务可见性和revision，日志不记完整签名。Revocation后新链接拒绝；已签发链接在TTL内的访问窗口需明确，不声称可瞬时撤回。
上传扫描、内容解码与预览使用隔离worker；压缩包展开限制文件数、总量和路径，禁止目录穿越。

## 7. 接口与事件（拟定）
`POST /api/enterprise/v2/assets/uploads`；`POST .../uploads/{id}:complete`；`GET .../assets/{id}/revisions/{rev}/download`。
产生 `asset.revision.ready.v1`、`asset.revision.quarantined.v1`；M11/M16/M18等待或中止交付操作。

## 8. 异常与验收
- 上传成功但回调丢失可按uploadId恢复；不重复保存多份大文件。
- 已验收引用存在时不能物理删除；删除请求有引用清单和保留说明。
- 跨租户签名、伪mime、损坏图、超大视频、压缩炸弹均有拒绝/隔离验证。
- 下载源文件/缩略图权限一致；素材复用可追溯但不重复算完整创作贡献。

## 9. 实现边界
已有Naumi私有媒体、对象存储适配和作品来源字段，但公司级DAM、源文件版本/使用权、扫描和交付引用待实现。媒体重任务不放在4核8GB主站同步请求内。

## 10. 开发工作包（本模块实施清单）
- **M13-W01** 数据：建立asset/revision/hash/tenant/scope/rights和业务引用关系，源文件不可覆盖。
- **M13-W02** 后端：实现直传/complete校验、扫描隔离、预览队列、短时下载鉴权与引用保留。
- **M13-W03** 前端：实现任务素材库、上传恢复、来源/版本、处理状态和受限下载操作。
- **M13-W04** 验收：跨租户同hash不共享、损坏/伪mime/压缩炸弹隔离、验收引用禁止误删。
