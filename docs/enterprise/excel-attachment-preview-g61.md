# G61 团队排期Excel附件内嵌预览

## 需求与实施范围

用户要求排期附件中的Excel支持内嵌查看/预览。本轮交付只读抽屉，不修改Excel、不转成工作任务、不增加文件公开地址，不接外部Office/WPS预览服务。原排期页、来源文件、工作库、权限与CAS保持；不操作47或发布企业独立服务。

## 产品入口

- 工作表附件单元格中，含 `.xlsx/.xls/.xlsm` 时显示“预览”；原附件管理入口保留。
- 附件管理列表逐文件增加“预览”和“下载”。进入预览后“返回附件”回到同一列表，未保存的附件选择由原闭包保留。
- 原始源记录详情的Excel附件同样补预览入口。
- 同单元格多个Excel可通过文件选择器切换；底部为原工作簿可见工作表页签。工作表横纵滚动、75/100/125%缩放、单元格地址跳转、200行/48列分窗口浏览。
- 只读单元格显示格式化值；点击后公式栏显示公式或文本。缓存结果保留，不重新运算、不执行VBA；缺缓存明确“公式未缓存”，零不变空。

## 实现与依赖

新增excel-preview-ui.js/css/worker.js。通过现有sgFileUrl和当前作用域从同源附件鉴权接口GET，明确same-origin credentials/cache=no-store，正式工作区带原viewer header，403/401/404不展示旧工作簿。请求有60秒超时与64MiB读流上限；关闭/更换文件/换workspace/pagehide中止下载、终止worker、释放Blob URL和待响应Promise。worker消息有30秒超时，不把主线程阻塞。

本机实际56个Excel附件，最大37,669,505字节，部分XLSX有124个图片对象。只做sheet_to_html会遗漏产品图，本轮单独读取XLSX drawing关系及图片锚点，仅向主线程传当前窗口内的PNG/JPEG/GIF/WebP字节；外部关系不跟随。表格文本经esc，公式只作字符串；从源值不生成HTML、链接或事件。

SheetJS CE0.20.3与JSZip3.10.1以固定vendor文件、许可和SHA进入完整单HTML构建，bundle-spec/assemble在构建时核对原字节；不改根依赖或锁文件，无运行时CDN。worker源码字符串转义 `<`，第三方许可证/格式命名空间URL不当作外部请求。静态检查仅对这个固定vendor字符串作隔离，主程序仍禁止外链与WebSocket/XMLHttpRequest；worker应用入口也显式无网络API。

XLSX先读取ZIP目录并只解压工作簿/单元格样式/共享字符串/metadata/工作表XML后交SheetJS；不将全部产品图交给SheetJS解压。drawing图片按窗口读取，限制64MiB输入、单XML32MiB、主要XML总96MiB、ZIP条目10000、预览前10000行、每窗200×48、每窗最多128图片/48MiB（单图24MiB）。超出行数或图片预算在页面提示，不静默当完整。

## 显示边界

XLSX支持单元格、合并、行高列宽、基础字体/颜色/对齐及上述内嵌图片；旧XLS只保证单元格，不还原其OLE图片/图表。图表、透视表交互、宏、外部数据刷新、复杂条件格式和Excel原生打印版式不属于本轮像素级复刻。原文件始终可下载。`.xlsm`按工作簿只读解析，VBA不运行；本轮真实样本为XLSX/XLS，未把真实XLSM验收写成完成。
