# A+ 详情图生成状态

更新时间：2026-09-14

## 已完成

- A+ 接口支持一次上传 1–3 张商品实拍图。
- 生成详情模块前，逐张清除实拍背景并生成纯白底商品母图。
- 白底母图会落入现有图片存储，并作为后续视觉规划和图生图的唯一商品参考。
- 结果区按“白底母图 → A+ 模块”的结构展示，便于核对正面、侧面与背标一致性。
- 白底阶段和详情图阶段分别显示进度文案。
- 流程已拆成“白底母图准备 → 用户逐张审核 → A+ 模块生成”三段；母图未全部通过时不会进入 A+ 生成。
- 每张母图支持独立“通过”和“打回重做”。打回时必须填写本张修改要求，后端会把固定主体提取规范与用户要求一起提交，只替换这一张。
- 母图保留版本号、返工要求、图片地址和时间记录，可回看历史版本；重做失败时不会影响其他已通过母图。
- 母图和最终 A+ 图统一使用全站图片查看器，支持点击放大、滚轮缩放、拖动和下载。
- 积分在“全部母图通过并确认生成”时才预扣，停留在审核阶段不会占用积分。
- Agent 已拆出母图准备、单张审核/重做、确认生成三个工具，并明确禁止在用户确认前自动通过。

## 当前限制

- 白底母图仍由图像编辑模型生成，极小包装文字可能发生细微重绘；上线验收需要人工放大核对标签。
- 一次任务会比原流程多执行 1–3 次图像编辑，耗时和上游 API 成本会上升，但暂不额外增加用户积分扣费。
- 当前异步任务状态存于单进程内存，服务重启后未完成任务会失效。

## 后续建议

- 接入像素级抠图服务后，优先采用“透明抠图 + 白底合成”，进一步降低包装文字漂移。
- 把当前单进程任务状态迁移到持久化队列，使母图审核任务可跨服务重启继续。
