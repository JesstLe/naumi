# A+ 详情图生成状态

更新时间：2026-09-12

## 已完成

- A+ 接口支持一次上传 1–3 张商品实拍图。
- 生成详情模块前，逐张清除实拍背景并生成纯白底商品母图。
- 白底母图会落入现有图片存储，并作为后续视觉规划和图生图的唯一商品参考。
- 结果区按“白底母图 → A+ 模块”的结构展示，便于核对正面、侧面与背标一致性。
- 白底阶段和详情图阶段分别显示进度文案。

## 当前限制

- 白底母图仍由图像编辑模型生成，极小包装文字可能发生细微重绘；上线验收需要人工放大核对标签。
- 一次任务会比原流程多执行 1–3 次图像编辑，耗时和上游 API 成本会上升，但暂不额外增加用户积分扣费。
- 当前异步任务状态存于单进程内存，服务重启后未完成任务会失效。

## 后续建议

- 接入像素级抠图服务后，优先采用“透明抠图 + 白底合成”，进一步降低包装文字漂移。
- 增加白底母图人工确认/重做入口，再进入批量 A+ 生成。
