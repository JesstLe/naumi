# 画布功能状态

更新日期：2026-09-14

## 目标链路

进入画布 → 创建项目 → 上传或引用素材 → 节点移动与重命名 → 节点连线与多输入 → AI 生成衍生图 → 保存作品与坐标 → 刷新恢复 → 下载、删除、撤销与回收站恢复。

## 本轮已处理

- 画布项目及作品接口绑定真实登录态，写操作不再信任前端提交的邮箱。
- Supabase 模式下，画布的上传、重命名、坐标、连线、删除和回收站请求统一携带访问令牌。
- 服务端校验连线两端必须属于同一用户、同一项目，并再次执行防环判断。
- 占位节点上传补齐授权头、HTTP 状态判断与可见失败反馈。
- 项目 ZIP 下载兼容自托管默认的 `/media/...` 本地存储图片。
- 项目聚合兼容 `/media/...` 节点，修复本地上传成功后节点从画布消失。
- 生成前先清理进程重启遗留的过期积分预约，修复孤儿预扣占满余额后账号无法再次触发自愈的问题。
- 增加接口、真实浏览器交互、真实模型生成三层画布冒烟脚本。
- 移除前端全局生图锁，改为节点级生成任务：同一节点防重复提交，不同节点可同时生图；任务各自显示、拖动和结束，不阻塞添加节点、上传或操作其他节点。
- 生成数量从固定 `1/2/4` 改为可输入、加减的 `1–8`；API 继续做 `1–8` 边界校验，多图结果按纵向节点完整落入画布。
- 下一节点默认引用当前节点结果，支持真实的“上传 → 提取主体 → 继续生成”链路，不再隐式跳回上一级素材。
- 增加三视图两种模式：一张横向正/侧/背合成图；或正面锚点完成后，侧面与背面并发引用“主体图 + 正面锚点”生成三个子节点。
- 增加“重做”操作：复用原节点提示词、比例、风格、清晰度和血缘，可在提示词框加入本次修改要求；旧结果保留，新结果作为新版本落图。
- 多图生成不再依赖上游一次请求的 `n` 参数，统一拆为多次单图请求；兼容服务即使忽略 `n>1`，选择 4 张也会真实执行 4 次并返回 4 个结果。
- 多图允许部分成功：保留成功图片，按实际成功张数扣积分，失败张数自动退回预扣差额；全部失败仍走全额退款。
- 并发闸按真实单图请求计数，多个节点和单个多图任务合计默认最多 4 路上游请求。
- 增加显式框选模式：开启后左键拖框即可部分命中多选，中键仍可平移，Esc 或批量工具条关闭选择。
- 多选后显示浅色批量工具条，支持把最多 6 张所选图片合并为一个多输入生成节点、批量标记/取消标记、ZIP 打包下载与批量删除。
- 多个已选节点可作为一组拖动，停止拖动后会逐个持久化坐标，并作为一次批量移动进入撤销/重做记录。

- 真实模型图生图成功，结果落入本地媒体存储并作为衍生节点回到画布。
- 真实生成结果的 `parentId`、`origin=canvas`、积分扣减和作品库展示均已核对。
- 容器重启遗留的过期积分预约会在下一次预扣前释放；用人工老化的真实预约回归通过。
- Docker 生产构建、TypeScript、Lint 和 Next.js 构建通过。
- 浏览器回归已覆盖自定义数量 `3` 的真实表单提交、两个独立节点同时出现生成任务、生成期间继续添加空白节点、三视图按“正面锚点 → 侧面/背面并发”提交。

- 真实 Chrome 已打开该批次并确认四个同级作品节点均完整出现在画布中，图片资源加载正常。
- 部分成功结算已通过故障注入：请求 4 张时模拟 2 路成功、2 路失败，最终返回并落库 2 张，仅扣 12 分，流水记录请求数与成功数，未成功的 12 分预扣自动释放且预约表归零。
- 真实 Chrome 框选回归已通过：拖框选中两个节点后显示批量工具条，整组拖动会分别保存两张图的新坐标，批量标记后选择不丢失；合并生成节点显示两张输入并建立两条输入连线。
- 框选回归同时验证未再触发 React Flow 受控选择循环（React #185），并继续跑通原有并发生图、删除、撤销和回收站流程。

## 验收脚本

- 运行前设置 `CANVAS_SMOKE_PASSWORD`；`CANVAS_SMOKE_EMAIL` 可选，默认使用本地画布测试账号。
- `node scripts/canvas-smoke.mjs`：接口鉴权、CRUD、位置、命名、连线、防环、ZIP、回收站。
- `npx playwright test scripts/canvas-browser-smoke.spec.ts --workers=1`：真实 Chrome 画布交互闭环。
- `node scripts/canvas-generation-smoke.mjs`：真实模型生成、落库、父子关系和积分；会实际消耗测试账号积分。
- `CANVAS_SMOKE_COUNT=4 CANVAS_SMOKE_EXPECTED_COUNT=2 node scripts/canvas-generation-smoke.mjs` 可配合 `scripts/image-api-partial-mock.mjs` 回归部分成功与差额退款。
- `npx playwright test scripts/canvas-generation-view.spec.ts --workers=1`：真实画布 Dock 生成及作品库回流；会实际消耗测试账号积分。

## 已知边界

- 生图任务状态仍保存在单进程内存 `Map`；进程重启时任务结果不可继续轮询，但过期积分预约可自动释放。
- 单任务数量上限为 8，服务端默认最多同时执行 4 个真实上游图片请求；更多单图请求会排队，但不会锁住画布。
- 三视图一致性通过锚点图、共享参考图和强约束提示词提升；生成模型仍具有随机性，单张不满意时应使用“重做”并补充具体要求。
- 浏览器用例使用本机 Chrome，需要安装 Chrome；真实生成用例依赖已配置且支持 Images API 的模型中转。
- 仓库现有 3 条非画布 React Hook Lint 警告仍保留，本轮未修改对应模块。
- 画布主组件体积较大，后续应按项目浏览器、节点编辑器、生成 Dock 和弹窗拆分，但本轮不做高风险结构重写。
