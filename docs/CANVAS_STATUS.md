## 目标链路

进入画布 → 创建项目 → 上传或引用素材 → 节点移动与重命名 → 节点连线与多输入 → AI 生成衍生图 → 保存作品与坐标 → 刷新恢复 → 下载、删除、撤销与回收站恢复。

### 边界

- 只接收系统文件拖放，不把网页图片链接或画布内部节点拖动当成上传；项目列表页不接收文件，需要先打开/新建画布。
- 上传队列保存在当前页面内，刷新/关闭页面不会续传尚未完成的文件；失败项可按提示重新拖入，成功项不受影响。
- 占位节点内的“替换/上传这一个节点”继续保持单图语义；批量入口是画布拖放和右键上传。

## 已知边界

- 生图任务状态仍保存在单进程内存 `Map`；进程重启时任务结果不可继续轮询，但过期积分预约可自动释放。
- 单任务数量上限为 8，服务端默认最多同时执行 4 个真实上游图片请求；更多单图请求会排队，但不会锁住画布。
- 三视图一致性通过锚点图、共享参考图和强约束提示词提升；生成模型仍具有随机性，单张不满意时应使用“重做”并补充具体要求。
- 详情图组按模块顺序逐张生成，四张图会比普通并发四版耗时更长；前一张失败不会改变既定模块顺序，最终按实际成功张数结算。
- 浏览器用例使用本机 Chrome，需要安装 Chrome；真实生成用例依赖已配置且支持 Images API 的模型中转。
- 仓库现有 3 条非画布 React Hook Lint 警告仍保留，本轮未修改对应模块。
- 画布主组件体积较大，后续应按项目浏览器、节点编辑器、生成 Dock 和弹窗拆分，但本轮不做高风险结构重写。

## 2026-09-18：画幅策略升级（attention 裁切 + 纯色/透明底留白）

### 已实现

- `cropToRatio` 从固定正中心裁切改为 sharp attention 选窗：自动对齐画面“最有趣”的区域（主体/人脸），贴边的手、文字、道具不再被居中硬裁；比例差小于 1% 时仍原样返回；attention 找不到显著区域时由 sharp 自动回退中心。
- 新增 `padToRatio` 留白补比例：不裁任何内容，用指定背景把短边补到精确目标比例。
- 新增 `detectUniformBorder` 纯色边框检测：缩到 32×32 采样四边、逐通道与均值偏差均小于 14 判为纯色底；白底图/影棚纯色底自动走留白，补的就是边框本色（视觉无缝）；渐变、场景类背景不误报，仍走 attention 裁切。
- `enforceOutputShape` 按"留白优先"分流：真透明底（抠图且图片实际带 alpha）补透明；纯色底补同色（自定义尺寸路径同步从 cover 改 contain）；其余场景图 attention 裁切。请求了透明底但上游降级为不透明图时，不按透明底处理。
