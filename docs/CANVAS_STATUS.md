# 画布功能状态

更新日期：2026-09-12

## 目标链路

进入画布 → 创建项目 → 上传或引用素材 → 节点移动与重命名 → 节点连线与多输入 → AI 生成衍生图 → 保存作品与坐标 → 刷新恢复 → 下载、删除、撤销与回收站恢复。

## 本轮已处理

- 画布项目及作品接口绑定真实登录态，写操作不再信任前端提交的邮箱。
- Supabase 模式下，画布的上传、重命名、坐标、连线、删除和回收站请求统一携带访问令牌。
- 服务端校验连线两端必须属于同一用户、同一项目，并再次执行防环判断。
- 占位节点上传补齐授权头、HTTP 状态判断与可见失败反馈。
- 项目 ZIP 下载兼容自托管默认的 `/media/...` 本地存储图片。
- 项目聚合兼容 `/media/...` 节点，修复本地上传成功后节点从画布消失。
- 生成前先清理进程重启遗留的过期积分预约，修复孤儿预扣占满余额后账号无法再次触发自愈的问题。
- 增加接口、真实浏览器交互、真实模型生成三层画布冒烟脚本。

## 已验证

- 原生多用户模式下，未登录请求拒绝，前端伪造邮箱不会越权。
- 上传本地图片后，真实 Chrome 能加载 `/media/...` 节点图片。
- 节点重命名、拖动坐标、项目重命名在接口落库并可刷新恢复。
- 创建副本、父子连线、点击剪线、删除、撤销、回收站恢复均通过真实浏览器流程。
- 本地图片可打包为项目 ZIP，浏览器收到有效 `.zip` 下载。
- 真实模型图生图成功，结果落入本地媒体存储并作为衍生节点回到画布。
- 真实生成结果的 `parentId`、`origin=canvas`、积分扣减和作品库展示均已核对。
- 容器重启遗留的过期积分预约会在下一次预扣前释放；用人工老化的真实预约回归通过。
- Docker 生产构建、TypeScript、Lint 和 Next.js 构建通过。

## 验收脚本

- 运行前设置 `CANVAS_SMOKE_PASSWORD`；`CANVAS_SMOKE_EMAIL` 可选，默认使用本地画布测试账号。
- `node scripts/canvas-smoke.mjs`：接口鉴权、CRUD、位置、命名、连线、防环、ZIP、回收站。
- `npx playwright test scripts/canvas-browser-smoke.spec.ts --workers=1`：真实 Chrome 画布交互闭环。
- `node scripts/canvas-generation-smoke.mjs`：真实模型生成、落库、父子关系和积分；会实际消耗测试账号积分。
- `npx playwright test scripts/canvas-generation-view.spec.ts --workers=1`：真实画布 Dock 生成及作品库回流；会实际消耗测试账号积分。

## 已知边界

- 生图任务状态仍保存在单进程内存 `Map`；进程重启时任务结果不可继续轮询，但过期积分预约可自动释放。
- 浏览器用例使用本机 Chrome，需要安装 Chrome；真实生成用例依赖已配置且支持 Images API 的模型中转。
- 仓库现有 3 条非画布 React Hook Lint 警告仍保留，本轮未修改对应模块。
- 画布主组件体积较大，后续应按项目浏览器、节点编辑器、生成 Dock 和弹窗拆分，但本轮不做高风险结构重写。
