# 模切线转 3D 产品可视化状态

更新时间：2026-09-14

## 已实现

- 新增独立工具页 `/packaging3d`，并接入创作中心、顶部创作菜单和工具数量统计。
- 支持上传 PNG、JPG、WebP、SVG 格式的模切线 / 刀版图，单文件最大 16MB。
- 支持自动识别及折叠纸盒、邮寄盒、自立袋、套筒、瓶贴五类结构提示。
- 支持正面、45°、侧面、背面视角，哑光、亮膜、牛皮纸、金属膜材质，以及纯白、浅灰棚拍、简洁场景背景。
- 生成提示词明确区分刀线、折线、粘口和印刷内容：成品不显示施工线，印刷文字、Logo、条码、颜色和面板关系保持不变。
- 采用异步任务与轮询，支持 1K、2K、4K 输出；结果存入作品库 `packaging3d` 分类并保留原始刀版。
- 结果区并排展示原始刀版与 3D 成品，图片可点击放大、缩放、拖动和下载。
- Agent 新增 `generate_packaging_3d` 工具，可通过自然语言选择包装结构、视角、材质、背景和补充要求。

## 产品边界

- 当前输出是 AI 生成的产品视觉效果图，不是可旋转的 CAD/GLB 模型，也不替代印前结构打样。
- 异形、多部件或结构线不清晰的刀版，需要在“补充要求”中说明成品结构；后续可增加人工面板映射和多视角一致性生成。

- 真实图片接口纵向验证：将 900×560 SVG 纸盒刀版成功生成 1302×1208 PNG 包装效果图，施工线已去除，`NAUMI` 正面文字和右侧面完整可见。
