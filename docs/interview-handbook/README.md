# Naumi 项目面试手册

版本：v0.2 · 更新：2026-11-02 · 状态：完整面试流程＋详细问答版，持续增补。

## 1. 本手册要解决什么

以 Naumi 的真实业务和已核对实现为起点，学习中大型应用共通的工程原理。业务载体可以是电商、社交、出行或 AI 创作；共同问题包括并发竞争、一致性、资源上限、外部副作用、故障恢复和持续交付。

**中大厂不等于高并发，也不只有高并发。** 正确性、权限、数据规模、延迟、成本、演进和协作同样重要。我们学习的是可以迁移的约束与推理方法，不是把所有业务套进同一套中间件架构。

每题沿着这条链展开：

> 现场问题 → 朴素模型 → 反例撞墙 → 基本事实与不变量 → 详细答案与逐步推导 → 示例落地 → 分级追问及完整答案 → 证据与边界。

本手册是项目中的长期文档入口。后续对话优先修订原题；新主题才分配新题号。参考回答不自动成为学习者的亲身经历。

**真实面试顺序不等于知识分类顺序。** 默认从自我介绍和背景交流开始，再介绍项目与本人职责，接基础知识、选型、实际问题和变化条件，最后总结与反问。原有 HB-001—HB-012 是深挖题库，不再充当整场面试的开头。先看[完整流程入口](00-interview-flow/README.md)，再按面试官追问进入各章。

## 3. 怎么读与怎么继续

第一轮按完整面试流程阅读：HB-013 → HB-014 → HB-015 → HB-016 → HB-017/HB-018 → 按线索选 HB-001—HB-012 → HB-019 → HB-020。每个主问题都有直接答案、推导过程、具体示例和面试表达；每个 L1—L4 追问也有独立答案，不再以一句“要点”代替解释。第二轮可先尝试回答再对照；第三轮换成电商或社交场景重答，检查自己理解的是原理还是 Naumi 的名词。

追问等级与学习者掌握度分开：

- **L1 解释**：说清现象、术语和基本因果。
- **L2 推导**：从约束、不变量推导方案。
- **L3 变式**：应对并发、超时、重启和迟到执行者。
- **L4 负责**：交代取舍、观测、验证、恢复和推广边界。

当前包含 **20 个主问题详细答案＋80 个分级追问完整答案，共 100 组核心问答**。其中原 12 题保留用于项目深挖，新增 8 题补齐开场、背景、项目概述、职责、基础、选型、变式与反问。每题还附常见误区、跨业务迁移、项目证据与验证建议；方法篇的连续八问与跨业务练习也附示范回答。学习者掌握度均为“未评估”，读过参考答案不记为掌握，也不记为个人实战。

## 4. 事实与版本约定

- **源码证据**：首版按 `main` 基线 `56453c50e21f74e2746060240b4ee9df4b5aa667` 核对。引用使用相对路径和函数名；行号变化时重新定位。
- **本轮修订**：详细问答从手册首版所在的 `main` 提交 `6142f05ce160015c1894505367819cc4db3c40a0` 开始，未改变题号与产品代码。新增 SQL、时序、计算和故障注入方案均标为教学示例或验证设计，不冒充生产实测。
- **历史记录**：`docs/changes/` 是当时调查、实现与验证的记录，不代表今天的线上状态。
- **教学假设**：用于制造反例和计算的数字、时序会明确标注，不包装成事故或压测结果。
- **规则要求**：发布手册描述应当怎样执行，不自动证明流程已经完成或已经部署。
- **当前未知**：没有核查的生产版本、吞吐与学习者能力保留未知；10 万＋活跃用户是产品建设目标，不是容量验收结果。

上一轮对话读取的共享分支仍有旧版内存限流等实现；最新主线已存在 PostgreSQL 共享限流、强化租约校验和回执期限。手册以本节固定基线为准，不把旧实现继续称为当前实现。

## 5. 对话结束后的更新规则

1. 判断讨论归属，优先补充已有题号，保持题号稳定。
2. 在正文增加新反例、回答、边界或证据；同主题不重复建章。
3. 在对话记录里登记日期、题号、用户实际回答、已解决疑问与待追问点。
4. 只有观察到用户实际回答，才更新学习状态；记录依据，不笼统标“全部掌握”。
5. 新建题目时同步总目录、题目索引和更新记录；未展开内容放待补区。
6. 修改事实时记录新基线与来源；发现旧结论错误，明确更正，不静默掩盖。
7. 文档修改集中检查目录、链接、题号与差异；不因教学更新触发业务发布。
8. 每个主问题与每个分级追问必须有完整答案。不得退回“只有问题”“一行要点”或“等用户回答后才补文档答案”的版本；只有用户明确选择模拟面试时，对话界面才可以先问后答，文档仍保留完整答案。
9. 面试训练默认保留开场、背景、项目、基础、选型、深挖和收尾的自然顺序，不一开始直接抛生产事故题。候选人的学历、年限、任职、职责与指标未知时，使用清晰槽位，不虚构。
