# Naumi 多租户后台实施与验收清单

本文件配套 [PRD](2026-10-22-multitenant-saas-admin.md)。用户已确认三张图片、双端及租户详情范围；执行模型指定 GPT-6.1 Sol high。下列复选框保留初始工作分解，实际完成状态以末尾交付表、[58项验收矩阵](../changes/2026-10-23-saas-admin-acceptance.md)及[47真实验收](../changes/2026-10-23-saas47-production-acceptance.md)为准，不能把空框误解为当前尚未实现。

## 1 执行约定

1. 阅读仓库 `AGENTS.md`、`docs/AGENT_COLLABORATION.md` 和 PRD。使用自己的 `codex/` 分支/worktree；主任务的 PRD checkout 仅维护方案，执行者从固定 PRD 提交建立自己的工作树。
2. 首先打开三张原图；遵循已有 Product Design image-to-code 与 design-qa 流程，用户明确要求真实产品重构，复用现有 Next 应用和服务端能力，不搭建独立 Vite 静态样站。
3. 使用现有图标库、受控业务媒体和真实接口；隔离 UI fixture 可以使用示例数据，但应显式标记并不能部署为真实数据源。截图中的 128 家企业、50 席位等不进入业务常量。
4. 主执行者可分派后端租户、平台 UI、企业/创作 UI 等互不冲突模块；子执行者继承 GPT-6.1 Sol high。每人独立分支/worktree；共改文件先指定负责人，通过提交整合，不复制整个目录覆盖。
5. 先定义服务契约，再并行构建消费端。小步保存提交，每完成一个完整模块再集中验收；不对每次 CSS 修改反复运行全仓测试。
6. 每模块更新 `docs/changes/2026-10-22-saas-admin-refactor.md`，记录范围、接口、数据兼容、提交、验证、未完成和功能同步计数。每累计 3 个模块刷新并整合 main；整合前和发布前再次刷新。
7. 不读取或输出生产密钥，不重放历史收费任务，不为截图发起真实供应商消费。只读线上检查与隔离库验收分开记录。
8. 不能因一处现有构建失败就放弃其他可独立验证的模块。把既有失败与新引入问题分开；新改动造成的问题须修复。
9. 不以“已有团队隔离测试通过”替代新租户、媒体、后台任务和账务边界验收；不以编译成功代替浏览器验收。
10. 主执行者交付完成提交、集中证据、运行预览和缺口；主任务做最终复核及生产发布协调。没有最终上线回执，交付状态只能是开发/验收完成或待发布。

## 2 模块划分和依赖

| 模块 | 产物 | 前置 | 可并行边界 |
| --- | --- | --- | --- |
| M00 | 现状映射、契约、视觉 tokens、固定测试基线 | PRD | 根任务审查与依赖准备 |
| M01 | 租户仓储、权益、范围、管理 API、幂等审计 | M00 | 平台/企业 UI 可按已定契约开发 |
| M02 | 统一平台壳、总览、租户列表/资料/权益页、旧入口映射 | M00/M01契约 | 不直接修改企业核心服务 |

| M04 | 统一创作证据、来源适配、归属快照、私有媒体 | M00/M01范围 | 接入 writer 与读取 UI 可分工，记录明确入口责任 |
| M05 | 租户创作主从详情、平台全链路、企业裁剪投影 | M04契约 | 公共详情组件单一负责人 |

| M07 | 集中集成、跨企业验证、同尺寸视觉 QA、构建 | M01–M06 | 独立审查与根任务复核 |
| M08 | 最新 main 整合、候选与发布门禁材料、47 发布协调 | M07 | 发布串行持锁，不并行启动候选 |

M01–M07 完成前不得称“重构已完成”。数据和接口缺口必须解决或明确列为不能满足的验收项；不得通过隐藏一个必做页面缩小范围。

## 4 集中验收用例

下面是必须覆盖的业务断言，不要求每项一个独立测试文件。按模块用少量高价值集成测试验证，不写只复刻实现的断言。

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| A01 | 未登录访问管理 API | 401/403按既有身份契约；无敏感数据 |
| A02 | 企业 A 改 URL/请求体为 B 的 tenantId | 拒绝且不泄露 B 是否有记录/成员详情 |
| A03 | A 请求 B 的 creationId、assetId、账本 ID | 主记录与子资源均拒绝 |
| A04 | 企业端请求完整执行/供应商字段 | 响应中不存在内部字段，不仅 UI 隐藏 |
| A05 | 管理员只获实例运维范围 | 不因新导航/API 获得用户和账务管理 |
| A06 | 企业管理员改前端 role 或成员 email | 服务端真实身份和范围仍生效 |
| A07 | 角色修改为上级/循环/自我提权 | 事务拒绝，组织与审计事实一致 |
| A08 | 企业停用成员 | 仅 membership 失效；个人及其他身份按原规则，不写全站 banned |
| A09 | 最后所有者停用/移除 | 拒绝，企业仍有合法管理入口 |
| A10 | 企业或成员撤权后再次读取媒体 | 逐次鉴权代理拒绝；前端取消读取并清理 object URL；不宣称召回已下载字节 |
| A11 | 切 A→B，A 的慢响应最后到达 | B 页面不出现 A 数据；旧请求被取消/忽略 |
| A12 | 账户退出再换账号 | 所有企业查询、编辑草稿、媒体清理 |
| D01 | 新建租户连续点击/网络超时 | commandId 查询恢复，只创建一次，无半成品 |
| D02 | 两管理员编辑同租户 | 版本冲突不覆盖；刷新后可明确重试 |
| D03 | 缩减席位到低于有效人数 | 拒绝，不自动踢人/删账号 |
| D04 | 永久授权与明确禁用/0 限额 | null、false、0 语义不被默认值覆盖 |
| D05 | 暂停企业时有已接受付费任务 | 新请求受限；原任务按冻结快照恢复，无重放 |
| D06 | 员工离职后查看旧任务 | task tenant/actor 和账务归属不变 |
| D07 | 历史归属未知但该用户现任职企业 A | 不自动归 A；兼容视图准确标注且不计入确认指标 |
| D08 | 企业钱包尚不存在 | 不显示成员余额之和为企业余额，不提供假划拨 |
| D09 | 扩展迁移重跑/中断恢复 | 幂等、可恢复，旧表和业务数据保留 |
| D10 | 当前空间与父项目/会话归属冲突 | 拒绝覆盖，旧项目/会话 scope 固定 |
| D11 | 企业请求无权或企业暂停，个人账号仍有效 | 企业请求拒绝而非退回个人；个人请求不得借企业权益 |
| D12 | 企业上下文使用私人/其他企业素材 | 私人素材仅经明确选择进入本次企业输入；其他企业对象ID直接引用拒绝 |
| D13 | 企业创作由成员个人账号付费 | 实际 payer 与原计费层一致；不扣所有者余额、不伪造企业债务 |
| D14 | 员工离职后所有者与部门管理员看历史 | 所有者保留已确认企业资产；岗位管理者遵守当前下级范围；私人未确认历史不扩大 |
| C01 | 新图片生成含2参考图和蒙版 | 素材角色顺序、原话参数、结果与账本可追踪 |
| C02 | 模型输入被压缩/转换 | 显示原始与处理后差异，不冒称原图 |
| C03 | 配置显示名/价格改动后查看旧任务 | 仍显示接受时快照；缺历史快照明确未记录 |
| C04 | Agent 一轮调用多个工具 | 一个顶层记录，子任务明确，费用按operation去重 |
| C05 | 同步工具失败/零积分 | 记录可见，失败与已知零分别准确 |
| C06 | 套图/A+部分成功 | 成功产物保留；未成功项与结算按真实证据 |
| C07 | 视频排队/运行/取消申请/状态未知 | 不误报完成或已取消；无自动重试收费 |
| C08 | Worker 重启后恢复任务 | 归属、请求、配置、计费与证据引用保持冻结 |
| C09 | 证据落库失败但供应商已接受 | 可恢复待核查，付费请求不重放 |
| C10 | 复制/导入作品 | 显示来源关系，不伪造本次生成步骤 |
| C11 | 同一source/事件重复回调 | 单一业务记录/事件，无重复产物和扣费汇总 |
| C12 | 输出多图片/文字/视频 | 完整分页/按需查看，不被固定单图详情截断 |
| C13 | 原素材已删除/失效 | 显示不可用；业务成功状态和账务不被改写 |
| C14 | 恶意 HTML/SVG/路径/外部地址 | 安全渲染或拒绝，不能脚本执行/路径遍历/SSRF |
| C15 | 只打开详情或重试读取 | 供应商调用与业务财务写入均为0 |
| C16 | 待核查与实扣未知 | 不用张数×现价填充，不显示成0 |
| U01 | 平台导航所有一级入口 | 唯一激活、真实路由，无重复完整侧栏 |
| U02 | 钱包与充值入口 | 首屏为正确钱包/充值内容 |
| U03 | 租户详情各标签及返回 | 企业上下文不丢失，按钮有真实行为 |
| U04 | 刷新/复制详情链接/前进后退 | 企业、日期、用户、状态、页码、记录恢复 |
| U05 | 200字中文标题/长email/媒体路径 | 列不溢出、不覆盖其他字段 |
| U06 | 数据加载/空/503/局部失败 | 有区分状态和重试，旧企业数据不充当新数据 |
| U07 | 三张核心屏幕同尺寸比对 | 导航宽度、层级、间距、密度、颜色与已选图一致 |
| U08 | 390px/键盘/焦点/Esc | 核心流程可完成，无页面横向溢出和焦点丢失 |
