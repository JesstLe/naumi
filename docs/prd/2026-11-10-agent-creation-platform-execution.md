## 1. 执行与责任

- 主执行者负责每个阶段的模块交接、集中验收和主线整合；尚未分配的工作包明确为“待认领”，不能把表格中的业务模块当成已分配人员。
- 当前文档负责人：本轮Codex主执行者。业务工作包负责人：待各阶段开工登记；产品范围按用户目标及PRD，成片审美终验由具名验收者记录。
- 未得到明确并行授权时按阶段顺序推进，不自行启动其他Agent。已存在的其他任务保持原负责人和分支，整合前先核实，不重复开发。
- 每个工作包使用独立短命分支/worktree；开工与合并前刷新main，选择性提交，集中验证，普通合并推送，当日清理已合并任务资源。
- 受影响关键假设提前最小验证；模块完成后集中测试。纯文档仅检查内容、链接与差异。每完成3个功能模块同步主线，文档不计数。
- 每包登记固定SHA、职责、公共接口、数据/事务归属、调用方迁移、验证证据、残留问题和下一步。没有最终产物与关键路径验收不标完成。

### P1 接入、项目、素材（R01–R04）

- [ ] **W01 能力总清单**：从在用页面/业务入口、Route应用用例和工具注册表交叉盘点。每项记录功能ID、用户动作、个人/企业/管理员角色、读写/费用、现有入口、目标工具、缺口、证据及阶段。按动作计分母，不按页面数或工具数凑覆盖率。
- [ ] **W02 项目与契约**：实现/适配项目查找和创建、节点发现与稳定引用；统一schema、错误和分页。验证企业空间及revision冲突。优先复用project/catalog与canvas服务。
- [ ] **W03 多媒体进出**：接通视频/音频参考上传、探测与资产身份，统一CLI/MCP参数；沿现有上传服务限制，不在客户端猜大小。相同operation重试不重复资产，下载支持私有媒体和续取。
- [ ] **W04 接入验收**：CLI和MCP均完成发现→项目→上传→读取→下载；更新真实命令与示例。MCP实现以现有stdio为基线。

输出：可执行能力清单、接入契约、三类素材样例与项目链接。集中验证：原网关smoke按受影响项扩展，实际HTTP/隔离PG、CLI、MCP；权限与媒体隔离必测。退出：AC01、AC02。

### P2 图片创作（R05–R06）

- [ ] **W05 图片任务闭环**：现有生成/编辑/专业图片工具按目录逐项适配；批次归项目、单图回执和多输出完整。
- [ ] **W06 质检与修改**：将图片检查结果结构化并定位具体产物；保留主体/文字/构图要求；重做指定图不会重跑整个批次。

输出：产品主图与详情图样例、质检记录、原图文件、单张改图前后版本和账务证据。集中验证：图像参数/冻结报价、批次失败与续交、参考归属、真实画布接手；最终图片必须打开检查。退出：AC04。

### P3 剧本、分镜与镜头（R07–R11）

- [ ] **W07 创作方案**：将目的/风格/时长等简报与原稿、角色、场景、镜头计划关联；用户只要剧本时不提交生成。保留原稿和改写稿的版本关系。
- [ ] **W08 角色与场景**：适配已有角色/场景/外观、正式参考身份，补镜头连续性检查与必要参考图生产。
- [ ] **W09 镜头制作链**：复用视频工具与持久workflow，跑通独立/依赖镜头、已有结果复用、取消、恢复与拼接。检验不同模型的真实能力限制和配置冻结。

2026-11-10增量：VV-03已补正式方案列举／读取／完整保存、审片采用、预检和粗剪业务工具，制作链计费与执行共用明确方案id/revision。复用既有方案、连续性、工作流和多轨 owner；[交付及证据](../changes/2026-11-10-storyboard-agent.md)维护本地验证与真实Agent／客户端待验收条件。本增量只覆盖W07–W10、W13、W15中正式分镜接手部分，不据此勾选整个工作包，也不重复新建分镜或多轨。

开工先检查已有分镜/导演任务是否已合main；不能从本计划旧基线复制覆盖其新实现。

输出：完整原稿、分镜表、角色/场景资产、实际视频、制作链状态和成本。集中验证：原稿覆盖、独立镜头并发、依赖等待、素材归属、恢复/局部重做，沿现有storyboard验证脚本扩展。退出：AC05、AC06。

### P4 剪辑、声音与字幕（R12–R15）
