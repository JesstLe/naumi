# 模型工具范围与全站版本

## 工具范围

在模型行提供“编辑范围”，分组勾选工具、全选可用工具、清空、恢复当前范围和搜索。显示已选数量，保存直接使用既有 MVP 独立发布流程。移出全部工具后仍可重新编辑该模型。

图片家族所有分支共享范围；家族主标题继续代表整个模型，原“配置别名”是其中一条旧分支名称，已改为明确家族说明。画布勾选会设为管理员默认模型；移除默认项时使用现有可用替代项，不能让工具失去最后一个模型。

范围保存在公开模型的可选 toolScope 字段，增加 nullable tool_scope 列；旧配置没有此字段，保持旧行为。不复制或生成新价格，不改变供应商、真实目标或原用途绑定。业务列表、能力和输入限制仍须满足；前端目录过滤与服务端新请求解析同时执行。任务描述继续从其冻结模型版本读取。

独立隔离数据库验收覆盖全家族、部分/全部/空范围、重新启用、默认回退、最后一个模型保护、请求拒绝、冻结任务、完整后台草稿与价格路由保留、结果未知重试、重复操作和版本冲突。真实浏览器验证上述编辑、家族说明、手机布局和保存后的目录。

## 网站版本

全站右下角常驻已加载代码的版本，点击查看服务器版本、固定源码提交并手动检查。每分钟和页面重新获得焦点时检查同实例的 /api/version；接口禁止缓存。

客户端版本在构建时内联，与 HTML 运行时查询独立，因此旧 JavaScript 不会伪装成新的服务器版本。版本不同（包括服务器回滚）时显示可更新和显式刷新按钮；刷新保留路径、参数和锚点，带服务器版本参数避免旧文档缓存。版本接口失败时仍保留已加载版本，不假报已更新。

新机 build-candidate 在 Next 编译前生成版本，并将同一版本和源码提交用于客户端与运行镜像。普通 Dockerfile 和 GitHub 镜像流程同步注入相同元数据。没有版本元数据的开发环境显示 dev。模型配置版本与网站代码版本分别标记。

浏览器验收覆盖当前一致、新版本、不一致的较旧服务器、检查失败、手动刷新和手机布局，均不提交付费生成。

## 发布与回滚

仅发布新服务器 120.27.162.85，先刷新主线、固定 SHA 打包、持公共 deploy.lock 备份及构建、确认运行镜像仍为基线，再切换并核验真实 UI 和版本。

迁移是附加 nullable 列，有五秒锁超时，失败不切换镜像。首次回滚至旧代码前须确认生效模型配置不含 toolScope；有后续真实范围编辑时须先在模型配置中心核对并恢复兼容版本，不能盲目切回不理解新字段的旧程序。回滚拒绝覆盖另一位同事的新镜像。
