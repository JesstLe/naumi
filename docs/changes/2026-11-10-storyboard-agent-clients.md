## 模块与职责

- 外部客户端继续使用已发布的 `public/agent/naumi.mjs`，CLI与其MCP模式共用实际网关。没有第二套客户端、业务服务或任务实现。
- `scripts/verify-storyboard-agent-gateway.ts` 只承担验收：实际子进程CLI、实际MCP SDK客户端／stdio、正式Next网关、正式方案／制作链／多轨和账务。只在带guard的独立本地PostgreSQL／fixture环境运行。
- CLI skill及MCP初始化指引补全正式方案、嵌套JSON、明确采用版、指定粗剪、外层与业务层两个操作编号的区别；不改变已有收费确认、预算或权限规则。

## 公共接口、依赖方向与事务归属

客户端 → 现有 `/api/agent-gateway/v1` → 现有工具注册／Harness／报价 → 现有正式方案、制作链及多轨接口。网关拥有令牌预算和外层回执；方案拥有revision/CAS和采用；工作流拥有冻结与生成；多轨拥有工程。各模块事务边界保持，不直接拼接生产数据库状态。

新增测试由既有真实App验收器的独立子进程执行，凭据仅通过fixture环境或本机进程内传递。调用断网代理只在真实上游响应已提交后丢弃客户端连接；它不是伪造业务响应。令牌在结束时吊销。
