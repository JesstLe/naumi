# 公开创作案例库

## 模块与职责

- 图片与短视频案例共享于首页发现区和 `/templates`。不修改原模板数据库、私有提示词、作品或收藏归属。
- `src/lib/creation-cases/` 拥有静态案例、检索、真实创作入口；`components/templates/` 负责筛选、卡片和详情。原 `TemplatesClient` 继续拥有数据库模板查询、分页和收藏。
- 浅色默认，复用全局双色主题变量；无营销标语。图片按已知尺寸保留槽位。列表只取封面，视频在详情显式播放，关闭卸载、页面隐藏暂停。

## 调研与来源

- 12 张图片来自 `jamez-bondos/awesome-gpt4o-images` 固定版本 `3ed4dbb0f1ae6f7385c81e1fcea48d9eefd2e596`。逐条读取 `case.yml` 与 `ATTRIBUTION.yml`，选择明确标注 `CC-BY-4.0`、由 Jamez Bondos 重新生成的成品。保留原提示词作者与原链接。
- 6 段视频来自 `genmoai/mochi` 固定版本 `15c9bad662df1fa3e7b53136423695b286484c08` 的 `assets/grid.mp4`，仓库 Apache 2.0。原片是九宫格，提取其中六个独立镜头，每段 848×480、5.433 秒、无音轨，不能称为六次独立生成。未引入模型权重或供应商配置。
- 图像转 WebP；视频裁切后编码为 H.264/yuv420p/faststart，抽取 1 秒封面。原始 URL/SHA256、固定版本、署名、许可、处理方式及本地文件 SHA256 维护在 `public/creation-cases/ATTRIBUTION.json`，许可证与修改说明一并随静态素材分发。
- 检查过其他官方模型演示，但未选用授权范围不清楚的外链媒体、输入动作参考、Git LFS 指针及 benchmark 拼图。第三方演示不宣称是 Naumi 生成结果。
