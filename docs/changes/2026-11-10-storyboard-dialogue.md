# VV-06 / W11：原稿、独立录音、字幕与正式工程导出

基线：`de1ab0bf831628b3804fbf85f755cc65ef29a9cc`。独立分支：`codex/storyboard-dialogue-20261110`。承接[顺序执行台账](../prd/2026-11-10-canvas-video-execution.md)第四项。

## 模块与职责

- 复用正式`TimelineProject`，可选`dialogue`保存逐句朗读台词、说话人、起止时间、原文快照、字幕和声音片段绑定；旧无对白工程不迁移、不增加默认字段。
- `source.text`保存经过正式文字节点校验的原稿快照，`text`保存当前朗读意图，`subtitleText`单独编辑。改台词不自动改原稿、字幕或录音；与录音时的`audioText`不同会明确提示声音待重录／核对。
- 声音仍是既有audio/video轨道的真实片段。逐句`audioClipId`只关联确切片段，不创建第二套音频工程或声音队列。一句可以跨多个画面，只有一个独立声音片段；不按切点重复台词。
- 添加录音仅修改该句所属对白声音片段，保留视频、配乐、其他句、裁剪／音量／淡变；原素材保持。删除对白仅移除该句拥有的声音片段，不删除手工绑定的其他音频或视频原声。
- 多轨仍拥有时序、混音、导出、采用、undo/redo与草稿恢复；媒体job拥有冻结请求、执行、私有存储、计费和取消／重启恢复。

## 能力盘点与完成层级

主线现有独立音频模块仅有导入／裁剪／增益／淡入淡出和采用，原视频可带原声；没有查得本次可调用的独立配音或转写供应适配。不能把视频原声当独立配音完成，也不根据模型名称猜音色或语言。

本模块完成**已导入录音＋人工校对时序＋字幕＋导出**路径。初始原稿时间按现有镜头位置／文字长度分配，并标记`timing=draft`；用户听录音修订并明确确认时间。它不是语音识别或自动对齐。真实生成配音、音色／语言目录、转写和供应费用仍待真实通道盘点与验证，VV-06/W11整体不勾完成。

## 公共接口、依赖方向、事务与恢复

1. `POST /api/canvas/storyboards/dialogue` / `apply_video_storyboard_dialogue`接收明确方案revision、目标关联粗剪及revision、稳定operationId。通过原`RoughcutIntent`持久意图／回执协议追加缺失原文；同句按正式源节点＋hash＋范围去重，保留已有人工时序、声音和字幕。原稿SHA已变或目标冲突时拒绝，不部分覆盖。
2. `timeline/dialogue.ts`是纯schema与规则；方案用例编排原稿读取与时间线公开服务。时间线保存校验新原文声明的正式归属、SHA、范围与逐字内容；已有精确快照可保留，改台词不使历史原稿失效。相同原文范围不能分给两个句子。
3. 音频裁剪与字幕时间经过原`planTimeline`和实际媒体元数据验证。绑定不存在、无音轨、超出录音／工程范围、重复声音分配或重复原文拒绝。声音尚未准备不阻止继续保存字幕草稿，但不伪造已配音状态。
4. `timelineMediaRequest`通过既有媒体job输出MP4和私有`timeline.srt`；`burnIn`决定是否将生成的ASS叠加到成片。SRT保持原字幕文字，ASS控制字符作为普通字形处理；字幕文件是数据，不参与虚拟路径或滤镜代码插值。
5. 浏览器和ASS共用换行、安全边距与多说话人重叠布局。字号、颜色、上下位置、底色、烧录均可编辑；布局超出安全区拒绝，不悄悄截断。关闭烧录仍可导出SRT。
6. 媒体虚拟文件契约仅新增ASS/subtitles辅助路径的滤镜层转义，保持宿主路径拒绝和虚拟路径准入；支持Windows盘符。Linux媒体镜像增加`fonts-noto-cjk`，原sandbox准备脚本已复制字体目录。本轮Windows实际字形通过；固定Linux候选构建与线上字体验收仍归VV-02。
7. 实际链路发现辅助文件加密分存后内部`readMediaJobEvidence`未还原原配方，导致正确字幕导出被拒绝采用；现由媒体owner在内部证据读取时重建辅助文件。公开job视图不泄露加密配方，采用继续逐项核对冻结工程与输入字节。

网页制作面板提供“读取原稿对白到粗剪”，不自动生成或扣费。正式多轨中编辑逐句台词／字幕／时序、选择原声或导入录音、调整该句录音入点、试听、确认时间、下载SRT及渲染。异步读取录音期间锁定该面板操作，回执以当前工程合并，只应用到原账号／工程生命周期，避免覆盖期间其他改动。

新增薄工具`get_video_timeline`、`save_video_timeline`、`render_video_timeline`、`adopt_video_timeline`及上述原稿导入工具；共用网页HTTP／权限／CAS／媒体job，不让Agent写库或自行拼接FFmpeg。更新视频目录、读写分类、能力权限、进度名称、内部路径白名单、CLI skill、MCP指引及制作提示。
