# 自动比例跟随参考图，移除全局固定比例拦截

## 用户要求与边界

用户确认自动比例应跟随参考图，继续优化。独立分支以`8476603a`为父，保留有效图片正常交付/比例仅提示的纠正。本轮仅本地修改、验证和推送；不上线，不修改后台参数、生产任务、账单或供应商执行记录。

## 实现

- 保留按角色选择画幅来源：单图跟随原图；产品图+唯一构图参考跟随参考；蒙版/明确目标编辑保持目标画面；多张构图参考不猜来源；明确手选比例优先。
- 自动解析允许常见互质宽高，例如`1316:1755`，不再因化简后超过三位数而被全局拒绝。旧multipart入口移除只认七个UI比例的限制，统一交给实际通道能力判断；EXIF显示方向保持。
- 对已识别的GPT自定义像素协议，新`ratioContractVersion=2`可将参考比例解析成合法16像素网格尺寸。能在预算内精确表示时保留精确比例（例如`53:79 → 848×1264`）；其他比例选最接近的合法网格，不用方向档或方图替代。
- 依据2026-10-20实际读取的OpenAI Docs：自定义尺寸需两边16倍数、长短边比不超过3:1、单边不超过3840、像素655360–8294400。本实现的新增自定义尺寸收窄到长边1536、像素不超过1572864；既有12个标准比例像素表不变。只构造请求，不做返回图片裁切/拉伸。
- 新计划和新HTTP请求由内部盖章为v2；v1和无版本的已接受冻结任务保持旧请求算法。HTTP字段不允许绕过版本盖章。恢复不重新规划、不自动重放付费请求。
- 管理员显式参数映射、异步适配器比例枚举、后台功能开放列表及质量/分辨率设置仍是权威，不为“自动”静默覆盖它们，也不把未知模型当成支持自定义像素。极端超长图仍依据实际接口能力在受理前处理。
