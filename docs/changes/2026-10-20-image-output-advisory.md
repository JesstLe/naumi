# 输出比例偏差改为非阻断提示

## 用户纠正

用户指出上一轮规则太严格。最终交付标准调整为：取得有效图片即正常交付，比例偏差作为质量提示，不再把整个任务判成失败。不再通过新增“更宽阈值”决定图片是否交付。

本任务仅本地修复、验证和推送；不上线，不改生产任务/积分，不重放付费任务。

## 实现

- generate-image将比例诊断保存为独立`imagegenOutputWarning`，不再写入阻断用`imagegenOutputError`。实际图片、宽高、ratio与已有计费规则保持，禁止为追比例静默裁切/拉伸或自动重新生成。
- imagegen父任务聚合`warnings`并继续保存、格式转换等后续步骤，完成后正常`succeeded`；透明输出无有效透明主体、空结果、损坏图片、上游错误等仍走真实错误链路。
- 普通画布生成、空节点生成、手动查回执、刷新后恢复均以轻提示展示warning，不再进入生成失败状态。
- 已留存的旧单步骤比例失败回执可只读呈现为“成功＋提示”，前提是有产物且子步骤已完成、没有尚未完成的格式转换/蒙版等处理。保留旧数据库状态与收费，不触发供应商调用；多步骤/其他错误不伪装成功。
- 现有精确参数的请求预检保持：已知不被接口接受的请求仍在收费前拒绝。这与“已生成图片的比例质量提示”分开。
