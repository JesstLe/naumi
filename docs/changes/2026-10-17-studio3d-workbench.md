# 真实 3D 产品工作台（首个可用模块）

## 请求与入口

用户确认“创作 → 3D 工作台”，独立工程编辑，不是 AI 静态效果图；在独立 `codex/studio3d-workbench-20261017` worktree 从 main `a6a87ec4` 开发。共享 checkout 18 项未提交保持；不操作服务器、Worker 或原画布。

入口 `/studio3d` 与 `/desktop/studio3d`，`tool-meta` 单一注册进入创作中心与顶部创作下拉；普通工作台快捷入口、桌面工作台卡片。沿用 feature-access，custom policy 未授权时隐藏/拦截；不新增全站顶级导航，不替换包装生图或服装生图。

## 实现

- Three.js 0.186.1 / @types/three 0.186.0；只在编辑器挂载后动态加载，不让首页加载 WebGL。
- 精华滴管瓶、膏霜罐、包装盒的真实网格和毫米尺寸；PBR 哑光/亮面/玻璃/金属、主体/盖子颜色与粗糙度。
- 标签贴图映射到圆柱或盒体正面，支持大小/位置；PNG/JPG/WebP，12MB、解码尺寸限制、2048长边归一化，不上传供应商。
- 导入20MB内嵌资源未压缩GLB，加载前校验头、长度、版本、顶点/节点上限，禁止外部URI和远程decoder；保留原始材质，归一化显示。参数化模型可导出真实GLB。
- 本地环境贴图、三套灯光、曝光/背景、OrbitControls和5种相机预设；相机姿态与工程保存。
- PNG 1K/2K/4K、1:1/3:4/4:3、透明背景；同一模型四视角ZIP，不调用图像生成供应商。使用实时WebGL渲染，不冒充离线光线追踪。
- 工程完整schema校验、当前账号分区IndexedDB，明确“此浏览器”保存；工程JSON `.naumi3d` 导出/导入携带模型与贴图。保存失败、离开未保存、WebGL丢失有明确状态。异步加载序列避免旧贴图覆盖新模型，销毁几何/材质/纹理/环境/监听器。
