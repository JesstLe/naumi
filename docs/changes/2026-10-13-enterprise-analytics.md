# 企业老板经营分析（2026-10-13）

## 目标与进度
以103已上线的企业层级管理为基线，老板/admin查看全企业（含老板），总监/负责人只查看本人及全部下级；具有内容查看权限的岗位才能读取经营数据。原站App/Worker/desktop不换版，仅企业独立服务蓝绿更新。

1. 积分：实际扣费、返还、净消耗，按成员、用途、日期对账。
2. 时间：今天/昨天/本周/本月/近7天/近30天、自由起止日；按日/周/月展示趋势；同长度上期对比。
3. 成员：岗位、上级、正式/实习、活跃人数、消费排行、产出与任务状态。
4. 追溯：分页流水、操作编号、消费/赠送/调整等分类、完整CSV导出。
5. 风险：低余额、30天到期积分、7天到期实习生、停用账号、待核对结算。

当前：目标已实现并上线103。API/浅色UI、日期/成员/团队/用途、排行/趋势/流水/完整CSV、生产效率与当前风险均通过隔离/真实数据库/浏览器验收；源码副本实际回滚与网关回退配置验证通过。原站/工作台App、Worker、desktop继续原版。

## 指标口径
- 北京时间，起始日00:00包含，结束日次日00:00排除；周一开始。自由日期最大10年，CSV最多50000条，超限拒绝而非截断。
- 创作消费只计负向consume，排除credits.adjust及管理员调整；返还兼容refund以及批次source=refund但历史账本写为grant的返还。净消耗=期间消费-期间返还，允许为负。预占不是消费。
- 用途优先使用同账号计费操作关联；兼容已核对的旧生图、套图、A+、复刻、画布用途前缀。未知项明确“历史用途未记录”；不输出原始reason、quote、model、供应商或采购成本。
- 余额/预占/到期积分为实时账户快照，不受历史日期和用途筛选影响，受成员范围筛选影响。到期本金可能含预占，不能再加到可用余额。
- 任务以发起时间入区间，展示当前状态，异步任务与对应计费操作去重；没有可靠结果状态的同步操作标为未知，成功率仅成功/(成功+失败)。不把零费用释放当作成功。
- 作品仅统计区间内当前未删除的记录，不等同任务数；历史复制作品按保留的created_at计入，不声称全部为本企业新创作。作品没有稳定用途关联，因此用途筛选后作品/每张均耗指标显示不可用。
- 同期对比是紧邻前一段相同日数，不是固定同比；上期净消耗<=0时不计算百分比。
- 风险为当前全日期状态：可用积分<100、30天到期、实习生7天到期；结算待核对排除受保护的导入历史（启用历史guard时）。不自动停用、赠送或扣费。
- 查询在同一repeatable-read事务中重新校验授权、组织范围、岗位；权限读取使用共享锁，统计函数只执行SELECT。授权变更在下次请求生效。所有接口与导出私有no-store。
