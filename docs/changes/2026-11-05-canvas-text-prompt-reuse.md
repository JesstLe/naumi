# 文字记事本、图片连线输入与原图草稿复用

基线：`ca00b1f125fff1077277c3a3b0cbf5b7df4b34f3`。本轮仅代码整合，不部署 47/103，不调用生产供应商。

## 模块与职责
- 正文仍由文字节点 `content` 与既有650ms串行自动保存拥有；`prompt` 单独记录AI写作要求。正文箭头明确润色当前正文，不复用旧要求，不覆盖用户写作要求；输入/失焦/连线不调用模型。
- `linked-image-text` 解析同画布显式直接连线；`prepare-linked-image-text` 管理保存ACK、最新内容与scope门禁；Canvas只接入真实节点/ref/保存队列。图片草稿只保存补充输入，派生正文展示与冻结提交共用解析器，不写回草稿。
- 专用文字生图对话框仍拥有递归/合并/复刻配方，保存后冻结，不重复叠加普通直接连线正文。
- 图片版本历史拥有真实生成输入；独立节点草稿可复用。切换历史/撤销重做不反灌历史prompt；pending上传换真实ID迁移草稿但不改上传作品provenance。

## 已查明问题
1. 文字自动保存已有；正文模式缺少直接润色动作，空AI要求被前后端拒绝。
2. 已有图片未读取文字连线；空图片节点补充prompt会覆盖连线正文。
3. 拉线建图复制静态正文，源文更新后副本过期。
4. 切回上传版本以空历史prompt覆盖可编辑草稿；pending先写后上传没有迁移草稿。
