# 画布参考图编号与点击引用

## 需求
多张图片输入后，用户需要明确图片区分，并像参考平台一样点击缩略图在提示词插入对应图片编号。使用浅色现有创作栏，不引入富文本编辑器或新生成协议。

## 实现
- 普通图片节点的自动引用图、追加上传图，以及合并待生成节点的输入图统一显示「图片1、图片2…」。编号按实际发送顺序，英文为Image1等。
- 点击缩略图在当前提示词光标/选区插入`@图片N `并把焦点还给输入框；预览放到独立放大按钮，删除独立按钮不插入编号。
- 删除或调整同一节点的参考图时，已有引用跟随原图片重编号；删除被引用图会移除对应标记，不误指向下一张。切换节点不改写另一节点草稿。
- 修正extraPreviews变化时清理全部旧blob URL的问题：只释放移除的图片及卸载时释放剩余图片，追加/删除不破坏保留缩略图。
- 保留原有上传、生成、积分及媒体路径。本轮不调用真实供应商、不连接或发布服务器。
