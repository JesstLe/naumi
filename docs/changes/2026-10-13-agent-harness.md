## 威胁模型与边界

攻击输入不一定含“忽略规则”等词：测试覆盖 Skills 中恶意指令、工具结果不可信封装、伪造 system 历史/执行轨迹、模型直接 confirm=true、会话/账号混淆、未知工具、额外字段、重复写、取消、超长分块和输出中的秘密/外部追踪图片。

不承诺语义层完全识别任何提示注入，或仅靠正则保证系统提示词全文保密；硬保证落在工具权限、真实账号、资源归属、计费授权、执行生命周期及敏感凭据处理。预算为单进程运行限制，真实积分与幂等由原业务数据库/API兜底，不变更管理员价格/模型配置。已提交给上游的任务不因取消或超时自动撤销/退款，也不自动重复提交。

## 具体实现

- `harness.ts` 统一服务端权威、JSON/schema 上限、封闭对象字段、单次调用许可、参数绑定、单轮写去重、24模型轮/32工具/8写调用/780秒硬预算、工具超时及取消传播；运行审计仅含runId/code/tool/time，不含参数或凭据。
- 用户新消息只生成粗粒度能力集合：普通图片创作不能顺带启用ComfyUI或视频。未知写能力拒绝执行；语义识别存在假阴性时请用户明确动作，不能把 Skill/历史/工具文字用于扩大能力。
- 模型 `confirm=true` 不是授权：只读取本次真实用户精确“确认报价/同意/yes”等回复，绑定**最后展示的报价**、工具及完整参数、下一轮、10分钟有效期；价格/版本改变重新确认；授权使用一次。一次性 POST 返回 sessionId，后续确认沿用该会话。未确认/普通闲聊/插话不授权。
- 创作元数据与 Skills 从system降到不可信user上下文；工具文字封装为不可信结果。鉴权/冻结模型/计费API仍独立执行，绝不由封装标签负责安全决策。
- 工作台不控制cv-*；新增项目范围 `/api/canvas/assistant/control`，画布停止操作已接入，侧栏/小球仍共用当前画布。按账号+会话串行构造实例，防止并发首次请求创建不同保护状态。
- 内部接口白名单、写零重试、重定向拒绝、图片同源仅媒体路径、流式大小限额；公网图床仅HTTPS受信域名，IPv4 DNS结果检查并固定到TLS连接，防重绑定/内网/元数据地址；IPv6暂不拉取。已有本地/对象存储由授权作品上下文读取。
- 凭据从env/真实当前模型账户/请求凭证注册，响应、工具结果、轨迹与新持久化消息脱敏；文字跨块保留后缀直到可完整检查，不逐delta正则。短回复可能在消息完成时输出，长回复按安全行段流出。
- 前端工作台媒体及画布Markdown媒体只能指向站内媒体或显式公开图片基址，外域跟踪图片不发请求；原富文本/代码复制保留，不执行模型HTML。
- PiBridge真正适配底座无关工具并接入harness/计费回调；未传写预检则拦截。未使用的CodexBridge移除shell、环境继承和无鉴权回调实现，显式503，不静默回退。
- genchat历史读取/保存/删除使用真实登录账号；客户端email仅校验一致性，不能指定另一账号。
