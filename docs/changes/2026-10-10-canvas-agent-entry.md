# 画布 Agent 显式入口与显隐偏好

## 用户批准的交互

- 画布编辑区右上角始终展示图标加「画布 Agent」，不依赖图片选中，不藏在更多菜单。
- 桌面首次进入编辑画布默认展开，右侧并列宽 360px，不覆盖画布；项目列表不展示侧栏。
- 用户显式收起/展开后按账号保存偏好；手机刷新默认收起，即使桌面曾保存展开。跨 1024px 断点重新按当前视口恢复默认/偏好。
- 空白画布显示任务卡片，允许预填需求；选择图片后使用既有图片上下文对话。没有图片时发送/参考按钮禁用，不新增无图收费或后端契约。
- 图片节点「图片助手」仍是携带当前图上下文的快捷入口；右键菜单统一称「画布 Agent」。
- 收起不清空当前输入、对话与内存历史；不把消息写到本地存储。重新打开同一图片延续会话，切换图片保留草稿但清空旧图片对话。

## 实现

最新截图反馈：模型品牌图标、真实显示名和切换箭头已放在输入框底部原「Agent」位置，移除框外重复模型栏。复用文字模型目录/选择/鉴权请求头，不改模型 ID、路由与计费。输入框内模型入口采用轻量无边框样式，长名截断、加号与发送保持 32px；模型菜单用共享 portal 避开侧栏裁剪并自适应视口，支持键盘选择。只有 composer 显式启用此样式，其他画布文字模型入口保持原行为。

属性/OCR 接管时使用实际可见状态，跨桌面/手机断点仍保持单侧栏；此时点击全局 Agent 入口直接切回助手。

`useCanvasAssistantDisclosure` 将显隐状态从 `assistantArtworkId` 分离，只保存 `open/closed` 偏好；缺少存储时仍可操作。默认展开不自动抢输入焦点，用户主动打开才聚焦。OCR/属性面板暂时接管侧栏，不覆盖手动偏好。

`CanvasAgentToggle` 是带文字的常驻按钮，提供 `aria-expanded/aria-controls`。`CanvasAssistantPanel` 支持空上下文和隐藏但保持挂载，桌面 360px 侧栏、手机 8px inset 对话层，保留现有任务/参考/历史/输入样式。

常驻侧栏不能像弹窗一样阻止所有画布快捷键：桌面键盘拦截限制在侧栏内部；手机遮罩仍阻止底层操作。画布上快捷键继续可用，侧栏输入不触发画布动作。
定向修复质量选择触发按钮的常驻阻断标记：按钮只阻断本元素焦点内的快捷键，打开的菜单/遮罩仍是全局阻断层。侧栏内部粘贴不会被画布图片导入劫持。

右上 chrome 根据缩小后的真实画布宽度换行，1024px 桌面扣除侧栏后右侧操作转到第二行；极窄视口隐藏非交互积分摘要，保留 Agent、下载、模板和账户入口。
底部创建栏与视图栏同样依据真实剩余画布宽度分行，而不是依据浏览器整体断点，避免打开侧栏后两栏挤叠；Dock 统一避让升高后的底栏。

助手流式生成期间不切换锚定图片；切换项目/账号或离开页面时中止旧请求，并用请求 epoch 防止旧结果落入新上下文。收起侧栏不取消用户已提交的对话。请求正文、模型选择、计费操作 ID 和生图管线沿用现有实现。
