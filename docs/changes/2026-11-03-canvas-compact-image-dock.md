## 实现

1. 图片专用 `compactImage` 几何：普通最大宽620、正文自然增长但普通最高360；默认先找图片下方，再上方及侧方。展开目标420、最高480，宽屏优先图片侧方，保留对照图片。画布实在放不下时保留有边界的可滚动面板，不承诺任何窗口都同时放下完整大图与全部控件。
2. Shell/引用组件显式 `compact`：图片普通编辑器最小56、展开160；引用卡48px高横排，原缩略图、插入编号、角色、移除、来源定位保留；无引用时上传入口放在编辑区下，不占开头空行。只有body纵向滚动。
3. 图片工具栏常用动作保留，重命名/助手图标化；背景、视角、文案、图中文字、标注及替换进入已有更多菜单，原权限/禁用条件/回调保持。工具栏宽度不超过780且受画布边界限制。
4. 生成模式移入已有更多图片参数；模型、比例/尺寸、质量/报价、数量仍在主操作区。提示词优化、历史版本图标移入顶栏，保留可访问名称和原行为；引用@入口并入参考图条，避免另占一行。
5. 已有图片和空白图片同一紧凑接线，文字/视频默认路径不变。图片选择不再为了上方堆大面板预留220px，仍保持原最小视口平移与标题安全边界。
6. Render/live两入口共享纯几何；新增可变侧宽600–620随纯平移同步DOM width，避免仅left变而右缘越界。
7. `dockNaturalHeight`由原header/footer及body子元素自然高度测得，只有图片compact使用；不再把上次剪裁/展开后的实际高度当内容高度。原像素回归发现收起后高度变化，修复后保持同内容同位置收敛。
