# 恢复窗口时保留已加载图片

## 范围与实现

- 基线 origin/main c2634fb；独立 codex/image-focus-retain47-20261016，不修改共享 checkout。
- 原 focus 无条件 reset 会撤销所有 Blob URL 并清空 CachedImage，导致缩略图闪白。
- 普通 focus 保留 URL/已解码图片，后台复用现有鉴权 manifest，按原 64 项/12KB 队列批量校验且同 epoch 合并在途检查，不重新取图片字节。
- 同账号有效响应不触发显示重置；单资源明确 null 仅撤销该资源并通知对应组件；401/403/确认身份变化仍清空。网络、超时、429、5xx、无效或不完整响应保留当前图片。
- 退出、账号切换、跨标签页 BroadcastChannel/storage 退出、epoch 防迟到结果机制保留。未改 Worker、供应商、生图或比例逻辑。
- lazy 图片首次进入观察区后保持就绪，临时遮挡/切后台不再反向置为未加载；卸载和换源仍释放租约。已看过且仍挂载的节点会保留 URL，不提前加载尚未看过的图片，不承诺浏览器内存回收后永不重解码。
