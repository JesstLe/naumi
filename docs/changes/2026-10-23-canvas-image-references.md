# 画布图片引用与编辑目标

用户要求优化多前置节点的图片指代。当前任务基于 origin/main `7b1e970c`，在既有独立 worktree 的 `codex/canvas-image-references-20261022` 分支实现；没有触碰共享 checkout 或其他同事未提交内容。沿用本会话图像链路“修复提交、不发布”的范围，当前未变更线上服务。

## 已实现范围

- 已有图片节点、空白图片节点共用引用编辑组件，显示图号、来源名称、预览和来源定位；通过 `@` 或引用按钮插入 `【图N】`。
- 用途支持编辑目标、构图、主体和风格参考。更换目标后它排到实际传图首位，其余图号不变；编号绑定来源 ID，不依赖连线排序或坐标。
- 节点/账号/项目隔离的草稿保存编号与用途，移除引用留下编号记录，后加图片不复用旧编号。引用失效在提交前阻止执行，不悄悄替换图片。
- 普通生成将图号、用途、来源名称与来源节点信息随输入素材冻结；后端将提示词引用转换成实际传图位置，预览与执行使用同一个请求。旧请求未携带编号时保留原行为。
- 详情图及三视图保留既有流程，显式引用通过对应传图顺序和提示词关系说明衔接；原任务/未知收费任务不重放。
- 新结果节点不自动继承上一任务带绑定图号的提示词，避免旧图号在新节点指向另一张图；原作品提示词和本节点未发送草稿保留。
- 空提示词生成、空白节点、批量运行、改比例和重做均跳过无法绑定到当前输入的历史图号。重做按创作栏中实际显示的图片执行；三视图分图在没有编辑目标时先拦截，避免先生成正面才发现后续缺输入。
- 多图下载、上传和报价时冻结账号/项目上下文，切换后未受理的操作停止提交；报价后异步请求内容计算完成时再次检查。已受理任务仍由原流程恢复，不取消、不重放。
- 参考用途是默认规则，用户在本次提示词中明确指定某图的使用方式时优先；不因默认构图用途阻止用户指定主体替换。
