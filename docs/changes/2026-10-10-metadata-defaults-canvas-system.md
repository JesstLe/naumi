# 元数据默认质量映射与画布系统授权

参数设置先读取元数据库中精确供应商 ID + 实际模型 ID 的记录；不同供应商即使模型 ID 同名也不共用默认。库中新增默认 quality 编辑器，数据保存在已有 parameterMetadata.qualityDefaults，无新增库表。未配置逐档默认时，仅对已记录的标准原生质量按档位补齐，高于最高原生档位的展示项复用该值；任意供应商枚举需要明确维护，不猜测含义。缺少参数资料的新配置默认不发送 quality。

MVP 参数页展示默认来源、修订与各档默认值，允许从原生候选列表选择或手动输入；原样发送模式也可直接编辑并转成逐档映射。一键“使用元数据默认映射”填入当前默认。现有显式映射保留，不因库记录变化自动覆盖。元数据修订有冲突保护，刷新默认资料时保留用户输入；映射发布后成为版本化执行配置，历史任务不跟随后续库更新。手动改值重新标为待验证；积分价格独立。

画布范围改为单个“应用到画布”，展开列出模块及可用状态。图片／文字模型按能力分别授权并选择，七项原生画布模块保留各自绑定、参数与价格限制。toolScope.systems 的 canvas 标记授权后，符合能力的新画布模块可继承；旧的部分范围保持，用户勾选并保存后统一管理。图片选择在生图、扩图、改字、标注间共享，文字选择在文字、Agent、OCR 中共享，能力不符时采用该模块可用回退。Agent 对话需要图片理解能力，出图走图片池，不把图片模型拿来输出文字。

画布 A+ 内容图沿用 image.aplus 原售价与生成能力，通过画布上下文授权使用图片池；站外 A+ 工具仍遵守其独立范围。独立抠图处理器和 ComfyUI 不改成通用生图模型。无新增计费事实字段，已接受任务保持冻结执行。

验证：TypeScript；元数据默认原生 API 发布、手动／空值兜底、同名跨供应商、未知枚举、修订冲突和幂等冻结；实际 HTTP 模拟供应商验证 JSON／multipart／Flow 映射、忽略、价格／审计与历史策略；七项原生画布调用和报价、A+ 画布／独立范围隔离、图片文字交叉调用拒绝、Agent 看图限制、冻结任务；真实浏览器库编辑、默认恢复／覆盖、元数据冲突保留输入、单个画布勾选／模块明细、共享图片选择、排序／刷新／移除回退与手机；同事画布裁剪／替换／属性／助手整合回归通过。真实供应商调用 0。

回滚需要理解历史版本中的 systems 字段。单独固定兼容版本 855762070fa0a973f83cb3f9611b1f933cea57e6 基于365878e，仅扩展该字段的读取；隔离旧执行器验证历史画布系统快照、图片／文字／A+ 冻结任务可恢复。发布流程同时构建此回滚镜像；回滚镜像同时可读取当前和历史系统字段，正常回滚保留配置原样；专用受鉴权 scope-compat 操作可在需要恢复逐项管理时展开当前系统授权，已验证草稿、价格与历史快照保留。数据库与媒体不回灌。
