# 画布 Agent 工具执行与会话生命周期

用户已批准接通现有 Agent 工具执行器并发布新机。原侧栏仅纯文字对话，未连接工具，历史只在组件内存。

- 新 Agent 请求复用现有工具、后台文字多通道调度、工具范围、报价与幂等计费；旧纯文字请求保持兼容。
- 服务端核对当前图片及参考图的所有权，文字理解与独立画布生图模型分开。换色、精修、复刻与生图使用画布参数和真实参考上传。
- 输出归属当前图片和项目，展示工具进度、结果卡片及停止入口。收费写入不自动重试，已结算会话请求重放已有结果。
- 会话使用已有数据库表，按账号和图片隔离；支持历史列表、恢复继续、改名、删除记录，删除不删除生成图片。修复共享运行时持久化丢失字符串用户消息的问题。
- 服务重启恢复真实用户/助手角色；执行中禁止删除或改名。服务中断历史标记失败，流断开未收到完成帧不显示成功，停止保留已受理结果。
- 大额报价要求跨消息确认，阻止 Agent 同轮自行确认。现有其他工具继续遵守各自配置和计费，未配置供应商的能力不会因此自动可用。

定向隔离数据库验收：真实 Agent 工具执行、所属参考、画布模型范围、输出父节点/项目/位置、重放不重复、讨论不生图、类型隔离、单次4积分、重启恢复/继续/改名/删除、执行中保护、同轮确认拦截通过；真实收费供应商调用0。TypeScript通过。停止请求与失败历史持久化通过。

合入同事分支 codex/canvas-agent-entry（15c6c38）的常驻入口、显隐偏好和输入框模型选择。集中浏览器验证真实前端请求区分文字/图片模型、工具进度/图片卡片、刷新历史恢复/改名/删除及320/390/1024/1440布局通过；接口截获，不消费供应商。发布证据及实际版号在完成后补充。
