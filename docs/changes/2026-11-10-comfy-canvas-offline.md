# ComfyUI 工作流：无端点画布编辑

## 目标与边界

用户确认：工作流是创作内容，端点是执行资源。无端点时支持导入完整 API/UI 工作流、节点连线呈现、参数/位置编辑、折叠和保存重开；仅运行时检查端点和实际节点定义。

固定起点：`628c5e93d711e25bd29f0ab975527d7eba86c5e3`。独立任务 worktree，不触碰共享目录现有文件，不合入或修改 103 模型映射实验分支；47 发布暂停约定保持。

## 实现归属

- `comfyui/document.ts`：纯解析、原始 JSON 保留、API 拓扑布局、UI 位置/分组与端口连接投影、字段编辑。UI 编译使用运行端点的真实定义，含不明控件或旁路语义时保留文档并提示执行条件，不猜测参数。
- `canvas/comfy-node-*`：原生工作流聚合，复用现有账号/项目鉴权、CAS、操作幂等、文档生命周期与历史。内部节点不是图片作品，不伪造媒体或执行结果。
- `components/canvas/comfy`：浅色工作流分组；在 Naumi 主画布缩放/平移坐标系中展示实际节点与 SVG 连线，无外部 ComfyUI iframe 或独立编辑器。
- 公共库导入：API/UI 均接受，导入与完整数据读取不访问端点。按需添加画布实例，参数和布局归实例所有，不静默修改模板。
- 执行复用 `comfyui/run`、原请求回执和原生视频任务；端点只在运行/连接测试时访问。源图由实际输入决定，纯文本工作流保留无图执行；输出回到所属画布。

## 数据与交付

- 工作流 JSON 的未知字段完整保留。UI 文档位置原样读取，API 文档自动布局；参数与内部节点移动走既有画布历史，外层分组移动、复制和删除沿用原生文档协议。
- UI 自定义控件的语义若未由端点定义确定，运行阶段给出具体节点问题；文档照常可看、可编辑、可保存，不静默猜测可执行参数。
- 当前支持参数编辑与节点布局，不把它描述为完整 ComfyUI 连线/插件编辑器。原生项目分享的媒体快照协议暂不携带 Comfy 文档，命中时明确转到分组 JSON 导出，避免混合画布分享静默丢节点。
- 共享旧工作区、模型映射 103 隔离分支、线上服务均保留；本轮不执行服务器发布，不增加发布维护计数。功能模块同步计数在最终主线整合后归零。
- 本地备份、修改包、diff、验证与文件级回滚材料在上述证据目录；回滚只改代码副本，不回灌数据库，不删新文档，不重放任务。
