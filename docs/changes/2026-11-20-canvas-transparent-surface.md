# 透明图片直接融入画布

## 模块与职责

用户要求已去背景的图片在画布上直接呈现主体，而不是显示在一块白色矩形卡片中。只调整图片节点的展示表面，不修改图片字节、Alpha、生成模型、报价、作品归属、持久任务或下载。

基线：`b5b6d09b07eb57d2aee739185f726dd43a7d6546`，独立工作区 `E:/Workspace/naumi-unified-image-cutout-20261120`。共享 checkout 的其他未提交修改保持原样。

## 根因与实现

- `canvas-ui-node-card` 共用样式强制填充 `--canvas-ui-panel-solid`，未选中节点还被强制绘制矩形边框。真实透明 PNG 因此透出白色节点底板，而不是画布。
- 只有存在图片、且不是生成占位、视频或待补素材的 Artwork 节点才标记 `canvas-ui-image-surface`。图片像素负责自己的背景，不根据模型名或 PNG 扩展名猜测透明度，也不新增逐图 Alpha 探测、状态或请求。
- 图片表面背景透明；未选中时不画卡片边框/阴影；选中时保留现有蓝色边框、外环、缩放手柄、连接口和操作菜单。普通不透明图片依旧显示其自身背景，白色像素不被抠除。
- 文字、生成占位、视频、待补素材及图片加载失败反馈继续使用原有表面。导入装饰节点原本不铺白底，无需改动。
- 已有缩略图/预览使用保留 Alpha 的 WebP。新增实际编码像素断言，验证两档变体透明角落、可见主体以及原 PNG 不被改写；不修改媒体实现。

## 公共接口与归属

`ArtworkContent` 只向真实图片表面添加一个展示类，`globals.css` 定义其局部样式。节点身份、几何、选择、拖拽、缩放、图片加载、缩略图选择和持久化仍由原 owner 负责，没有新增 API、数据库字段或事务。
