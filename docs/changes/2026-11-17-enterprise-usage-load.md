## 模块职责与实现

- `EnterpriseHistoryUsage` 单独负责展开状态。额度首页保留当前企业汇总请求；成员历史明确展开后才挂载，收起或切换企业/账号时卸载并取消浏览器请求；取消每 60 秒自动刷新，保留手动刷新和筛选。
- 共用的 `TenantUsagePanel` 以租户及开始/结束日期的实际值作为请求依赖；同值的新对象不触发重复读取。真实周期变化、切换、手动刷新按原合同执行。
- `enterpriseAnalytics` 在原授权及一致性事务内先筛选流水，按 `(email, ledger_id)` 批量匹配收费记录，并保留最早创建时间与 ID 的决胜顺序。摘要、用途、成员、明细数量/分页和趋势复用一份当前范围分类；上期对比单独计算，分类由每报表 7 次减少为 2 次。退款分类仍验证准确 ID 前缀和付款账号绑定。CSV 和创作流水引用同一分类规则，数据库不新增索引、DDL 或写入，计费口径/权限、空值及未知语义不变。
