# 模型配置页新增前端模型入口

## 用户问题与根因
页面可以接入供应商、登记实际上游模型，但缺少直接创建前端展示模型的入口。既有“添加到可切换列表”只新增 upstreamModels，不创建 publicModels，二者不应混用。

## 实现
- 模型管理页顶部新增主入口“新增前端模型”，接入上游保留为独立次入口。
- 前端暂无可见模型时，空状态提供同一入口。
- 链接直达 `/admin/bi/models?tab=batch`，服务端继续执行原有管理员鉴权，仅接受明确 batch 初始标签。
- 复用既有 ModelBatchEditor：前端ID/展示名称、实际供应商模型、基础售价、应用范围、预览、草稿及统一发布流程。未重新实现模型发布或自动修改价格/默认路由。
- 完整配置中心增加“返回模型列表”；不修改共用CSS或共享未提交代码。
