## 交互实现

- `node-menu-items.ts` 管理菜单顺序、图标、启用状态与中英标签。
- `ContextMenuSubmenu` 将子菜单挂载到同一菜单焦点域，避开父菜单的滚动裁切和入场变换。
- 子菜单支持上下键/Home/End、右键进入、左键/Esc 返回；再按 Esc 关闭父菜单。鼠标穿越菜单间隙有短暂延时，边缘自动换侧/限高滚动。
