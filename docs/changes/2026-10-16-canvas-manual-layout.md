# 画布占位就近与坐标保留

## 用户要求
新生成的占位图就近出现；用户拖到指定坐标后不自动对齐。全局排布只在手动“整理画布”时生效。

## 实现
- 新任务按来源节点附近空位分配；拥挤列不再只往整张画布最底部寻找空位。同一事件内的并发任务同步预留位置。
- 已存在的空白节点启动生成时保留位置，不再次避让。默认关闭16px网格吸附，磁铁仍可由用户主动开启。
- 移除渲染阶段全树重排；仅缺坐标节点首次分配邻近位置。账号/查看对象/项目隔离的session位置缓存防止元数据/阶段变化和刷新触发重排，服务端显式坐标优先。
- 拖动中刷新保留ReactFlow实时位置；任务拖动同步更新该任务ref及原operationId的回执坐标，不重提付费任务。详情序列也使用拖动后的live坐标落地。
- 完成回填检查位置保存响应，不再吞掉失败；保留鉴权、模型/供应商payload、计费、租约和手动整理事务/撤销。
- 扩图/标注编辑与ComfyUI同步结果也读取实时占位坐标；单节点拖动保存失败会提示，不将仅本地移动冒称已持久化。
