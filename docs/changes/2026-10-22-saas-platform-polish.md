# SaaS 平台表单、成员管理与旧入口收敛

日期：2026-10-23；独立分支 `codex/saas-platform-polish-20261022`，从主实施 `f3e11e4e` 建立。原企业 UI 工作树的两份验证依赖保持原样，没有 stash/reset、共享 checkout 编辑或服务器操作。

## M02 表单与成员

- 租户权益以 `feature-access/catalog` 的实际功能 ID 构建分组选择，区分继承、显式开放、显式关闭。不要求管理员填写 JSON；既有扩展字段只读保留，缺失与 false 不混淆。
- 所有资料、席位、授权、状态、原因、负责人和复用对象的变更均使预览失效；最终保存仅确认当前完整 payload。预览逐项列出实际将保存的内容。未修改的精确授权时间保留，日期选择采用北京时间。
- 新建前核对负责人的真实已有团队和已开通租户；提供准确 `reuseTeamId` 明确选择，不自动合并。已开通租户给出直接维护入口；旧团队包含成员时继续执行服务端初始化门禁，不创建密码或改扣费。
- 409 保留草稿，可读取最新资料，采用最新版本时只合入未编辑字段，保留自己的改动并要求重新预览。
- 结果未知时冻结已提交草稿和 commandId，查询真实 `{tenantId,replayed}` 结果，支持同一操作编号重试；不再以不存在的 `tenant/result` 字段判断恢复。
- 平台成员页直接消费管理 API：加入已有账号、暂停/离职、恢复、岗位/上级/用工与期限编辑；岗位创建/权限编辑通过已有受平台凭据授权的 `/api/enterprise` 命令，不依赖企业账号登录。保留版本、幂等、原因（成员命令）、席位和组织错误。所有者不显示成员移除操作，服务端仍执行最后所有者保护。
- 平台日期显示上海最近7自然日默认值，和服务端口径一致；即将到期选项接主实施的新真实过滤。趋势消费主实施 `TrendChart` 折线面积图组件，不把柱图当目标视觉。

## M06 兼容入口

- 设置支持 `tab`/旧 `section`，别名映射到登录支付、品牌、页面、模板、提示词与兑换码；用户、作品、流水、计费和部署转到正式归属页面，保留用户、日期和其他查询上下文。不支持的旧标签明确提示。
- 保留旧用户用量及日期窗口，保留原账号积分调整、旧部署/中转密钥功能的兼容入口；兑换码和支付配置继续可达，没有仅删除菜单而丢失功能。
- 钱包、充值和全部已有计费 tabs 可直接深链，tab/feature 在 URL 恢复并支持前进后退；`section=wallet` 默认充值套餐。移除计费页额外 `BillingNavigation` 外层，复用共享壳导航与功能 tabs。
- 字典映射使用 own-property 检查，未知或原型同名标签不被当成有效目标。
