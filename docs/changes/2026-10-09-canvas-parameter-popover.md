# 画布比例与分辨率弹层修复

合入最新主线的 Dock 碰撞布局、画布 UI 和生成参数校验，并保留管理 MVP 的显示名称编辑。

原比例弹层固定向上展开，其高度限制按整个窗口计算；按钮接近顶部时，选项越出屏幕且无法滚动恢复。现在根据按钮上下可用空间选择展开方向，将弹层限定在窗口内；空间不足时内部滚动，滚轮事件不传给画布。窗口变化及 Dock 布局变化后重新定位，Escape 关闭并将焦点返回按钮。

参数范围遵循当前主线，继续只提供受支持的八种比例及 1K/2K/4K，不恢复旧的自定义尺寸入口。

验收：1200 个弹层边界场景；2625 个 Dock 碰撞场景；生成参数 288 个有效组合、90 个拒绝组合和 5 个真实路由；管理 MVP API/浏览器、模型家族路由及冻结文本规则。浏览器覆盖明暗主题、桌面/手机及矮窗口五种尺寸、打开时缩窗、滚轮与底部选项；确认无付费生成提交。线上界面测试使用隔离的浏览器数据，阻断全部写请求；显示名称验收使用真实配置并恢复原名。

发布仅操作 120.27.162.85，持有公共 deploy.lock 从备份到线上浏览器验收。固定提交镜像发布前验证运行版本仍与备份一致，保留生产配置、数据库及媒体。
