# Naumi 品牌小球原型

> 最新状态：默认石墨球眼睛已改为柔白 `#f5f5f7`，跟随已采用的 A / 胶囊 N 黑白品牌体系；主球/角落球/八状态缩略图同步，已更新新机。当前验收及发布/回滚详见 `2026-10-10-naumi-orb-eye-palette.md`；以下是最初原型调研与历史验收。

## 调研

- 参考 https://github.com/tycoding/grok-ball ，固定 SHA `de368ce3acdc5a70e871ee46ebbe8f60b11d3d6a`，MIT 许可证。
- 引擎使用纯 SVG、48 点眼环轮廓与球面经度投影，不依赖 Three.js/WebGL。共享 RAF、临界阻尼弹簧负责呼吸、眨眼、表情插值和自旋彩带。
- SDK 不自动监听鼠标，宿主将 client 坐标转为 `-1..1` 后调用 `setGaze`。球体按实际宽度/高度定位，小球使用至少 200px 的注视范围，避免鼠标一动就极限转眼。
- 原版 JS 未改动，许可证/版本/哈希保存在组件 vendor 目录。仅在 React 客户端 effect 内动态导入，避免 Next 服务端执行 window 全局。

## 已实现

- 独立 `/brand-orb` 浅色设计页，不放入工作台导航；仅此精确路径跳过工作台外壳，不改变鉴权、setup 门控与其他页。
- 默认石墨黑球、荧光黄眼睛，对应现有 Naumi Logo；另有靛蓝/珍珠预览。页头使用运行时 `useBrand()` 名称和 Logo，不重复硬编码白标名称。
- 8 个状态：待机、好奇、开心、思考、检索、处理中、完成、出错。缩略图静态渲染，主球和 64px 角落球共享引擎时钟。
- 鼠标跟随、点击/Enter/Space 自旋、重播、动画开关、角落球开关和收起按钮。触摸不监听跟随、不阻止滚动。
- `prefers-reduced-motion` 优先于动画开关，离屏/隐藏页停用实例；卸载清理 observer、媒体查询与事件、SVG、ticker。异步导入后的卸载也不会创建遗留实例。
- 独立可复用组件，不接业务 API/付费模型/数据库，不发布服务器。

## 集成方式

```tsx
import { NaumiOrb } from "@/components/naumi-orb/naumi-orb";

<NaumiOrb state="thinking" theme="naumi" followPointer motion label="Naumi 助手" />
```

父容器决定尺寸；`state` 可由业务状态映射控制。未接 Agent 状态、聊天入口或生产页面；点击只演示自旋。原引擎保留表情里的细节配色，主题覆盖基础体色与默认眼色，不篡改参考数据。
