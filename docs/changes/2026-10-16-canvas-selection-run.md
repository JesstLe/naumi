# 画布框选批量运行

## 要求与基线

用户提供框选多个图片节点及底部“批量运行生图”截图，要求画布框选可批量运行。独立分支/worktree `codex/canvas-selection-run-20261016` 基于开工刷新main `c2634fb`；共享checkout正有管理UI未提交改动，未切分支或覆盖。此前APIB适配/容量方案继续留在原工作副本，不混入本任务。

## 实现

- 复用React Flow真实选中集合，在多图片、多文字、图文混选以及带输入的待生成节点选择中提供批量运行入口；非执行视频/装饰/空白无输入节点不触发生成。
- 原本已有图片批量入口，但在横向滚动区域内，且使用全局草稿覆盖全部节点提示词/比例/分辨率。现在主动作固定在工具栏计数旁，不随其他动作滚出视口；保留组、合并、反推、标记、下载、删除和清除入口。
- 图片分别使用自身提示词、比例、分辨率、风格，以自己图片为参考，在原有生成管线产生子结果，不把所选图片合并成一次生成。Artwork没有独立模型/质量/张数配方字段，本入口使用当前画布模型/质量、每节点1张，不声称恢复不存在的历史参数。
- 文字节点复用原生text-generate和保存流程；带输入的待生成节点复用generatePend，不自动执行未选中的上游节点，也不重建工作流依赖。
- 同步ref阻止连点重复批次，节点级操作key与单节点运行共用。过滤锁定/运行中节点，排队取出时再次检查，两个工作协程执行，单项失败不终止其他项，结束显示成功/失败/跳过数量。
- 切换账号/项目停止尚未提交的队列；已有持久任务仍由既有任务恢复机制处理。后台鉴权、积分、供应商分流、媒体权限和持久恢复接口不变。
