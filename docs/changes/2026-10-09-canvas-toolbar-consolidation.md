## 梳理和实施范围

| 问题 | 整合方式 |
| --- | --- |
| 高频工具入口过少 | 文字/图片/上传/历史保留直接快捷按钮，＋保留完整创建菜单；用户可以不用，但不隐藏常用工具 |
| “生成衍生图”实际上聚焦节点；“连线”只是提示 | 移除误导性按钮，保留真实生成面板、节点聚焦和连线操作/快捷键 |
| 更多工具与左下视图工具重复 | 视图动作集中左下工具条，主Dock设置只留主题与快捷键帮助 |
| 加文案与改字容易混淆 | 生成文案排版与编辑图中文字区分，并说明新图/编辑结果行为 |
| 改比例与扩图容易混淆 | 重构比例与扩展画面区分，并说明重绘/补全画面行为 |
| “高清”容易被当作仅选输出分辨率 | 明确是AI增强生成新图，不是参数设置或无损放大 |
| 图片栏添加与生成面板参考图上传重复 | 参考图只保留生成面板入口，明确“添加参考图” |
| 文字栏引用与文字生成面板引用重复 | 引用入口只保留生成面板；工具栏保留文字生成/配图与节点操作 |
| 高频处理被收进菜单 | 重命名、图片助手、换视角、生成文案图外置，主栏前段优先展示；更多仅留重新打光/ComfyUI/视频 |
| 加号与箭头容器不匹配 | 所有底部工具统一移动端28×28、桌面36×36，18px线性图标；加号只保留颜色强调 |
| 质量框与两边控件大小不一致 | 模型、模式、比例、质量、数量统一32px高度，9px圆角；质量文字12.5px/semibold、水平padding10px，与相邻参数一致 |

图片、文字、主工具栏和视图工具栏统一可访问名称与图标语义，沿用浅色CSS令牌；不修改生成函数、提示词、计价、模型路由、保存/删除逻辑。菜单需支持键盘、Esc/外部关闭、焦点恢复和窄屏定位，避免横向滚动容器裁切。
