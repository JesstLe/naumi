# 创作设置面板「质量」选项一行排布修复（2026-11-12）

## 模块与职责
- `src/components/home/creation-settings.module.css`：创作设置弹层（`creation-settings-panel.tsx`）样式。纯展示层修改。

## 公共接口、依赖方向、数据/状态/事务归属
- 无接口/依赖/数据变化。`.choices` 为「清晰度」「质量」等文本选项行的共享样式类；`.ratios`（比例宫格）有独立 `min-width:41px` 覆盖，不受影响。

## 本次实现与迁移状态
- 问题：质量档位共 6 项（智能/低/标准/高/超高/最高），`.panel .choices button` 的 `min-width:43px` 使 6×43+5×3 间距+8 内衬 ≈281px，超过右栏约 266px 可用宽度，`最高` 换行独占一行（`flex:1` 拉满整行），排版失衡。
- 修复：共享规则 `min-width` 43→36px（11px 字号下 2 个汉字仅需 22px 文本宽），6 项平分一行（每项约 42px，容纳最长 3 字标签「高质量」）；选项更多或标签更长时仍按 flex-wrap 均衡换行兜底。
- 移动端（≤640px）规则未动：窄栏下 6 项自动 3+3 均衡两行。

## 验证命令、结果及证据层级
- 按真实列宽（278px）+ 真实 CSS 值渲染前后对比预览（html_preview 截图核验）：修改前 `最高` 独占第二行，修改后 6 项一行均分，`清晰度` 4 项行无变化。证据层级：布局级视觉验证。
- 纯 CSS 一处数值修改，无 tsc/eslint/回归影响面；`verify-creation-to-bottom.cjs` 等既有套件不覆盖该样式，未受改动影响。
