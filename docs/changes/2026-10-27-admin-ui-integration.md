## 集成中发现的客户端反馈缺陷

真实应用轮次中设置页出现一次“无权限访问”，后续同 cookie 的服务端鉴权仍返回已授权。另以受控断网独立复现：`/api/admin/login` 读取失败会落入 Supabase 分支，将有效本地管理会话误显示成无权限。修正只在客户端反馈层：验证读取失败保留关闭状态，展示“后台验证暂不可用”和“重新验证”；重试仍以原服务端结果决定，未放宽服务端鉴权或使用缓存跳过验证。原首次异常记录与受控复现均保留，不把它们概括为已证明完全相同的网络断点。
