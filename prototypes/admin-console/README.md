## 本轮已实现

- 浅色共用后台：品牌、分组导航、页头、全局搜索、通知入口、移动端抽屉导航。
- 运营概览：时间范围切换、指标、趋势、供应商用量、最近任务。
- 生成任务：状态、供应商与文本组合筛选，分页、密度切换、清空筛选、按当前筛选导出。
- 任务详情：右侧原生对话框，演示产物、父子任务状态、供应商、执行时间线、预占与结算分离。
- 模型与供应商：模型筛选、启停演示、参数/价格草稿、新增和修改供应商草稿。
- 用户：搜索、方案筛选、分页、详情与关联任务跳转。
- 账务：预占/结算筛选、关联任务跳转、演示流水导出。
- 公告：未读、全部已读、未读筛选。
- 设置：本次预览内保存字段和显示选项。
- `Ctrl/Cmd + K` 搜索、原生 dialog 焦点管理与 Escape 关闭、响应式布局。

无生产 API、真实认证、真实媒体、密钥存储、计费、任务恢复、服务发布。供应商表单不建立连接、不储存密钥；刷新页面恢复演示初始数据。公告和经营指标也是原型样例，不表示实际运营状态。

## 设计与实现

参考门店 ERP 的浅色导航、页头/筛选/列表层级、详情抽屉。保留 Naumi 现有胶囊 N 标志，以紫色作为少量操作点缀；不复制参考站品牌、用户信息或商业数据。不添加口号和重复解释标签。

单个自包含 HTML，内嵌样式、行为、数据与 Lucide 图标。三个产品/场景缩略图是本地 SVG 演示插画，不冒充供应商成图。无需 CDN。CSP `connect-src 'none'`、`form-action 'none'`，业务表单仅更新页面内存。

新文件位于 `prototypes/admin-console/`，不在 Next 应用路由或 `public/` 下；不随程序默认公开。未修改共享目录中的 18 项未提交变更，未合并重构分支，未操作任何服务器。
