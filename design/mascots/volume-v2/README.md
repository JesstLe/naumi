# Naumi 立体伙伴 v2

用户反馈平面稿像纸片人，本次改用 Three.js WebGL 实体网格；保留 v1 作为造型历史，不替换现有线上小球。

## 已完成
- 12 款不同伙伴、12 套彩色配色、20 组动作选择。
- 球体/椭球/圆角挤出体/管线等真实厚度，鼠标拖拽可看侧面；不是 CSS 图片 rotateY。
- 物理材质、环境反射、主光/补光/轮廓光、实时投影与径向接触阴影。
- 眼睛是凸起的亮面珠眼，耳朵、尾巴、手脚是独立网格。
- 耳朵尾巴小幅联动，动作控制躯干、手臂、眼睛、脚，跳跃含挤压和伸展。
- 鼠标目光、键盘动作、暂停、轮播、localStorage 角色选择；浅色响应式布局。
- 本地固定依赖 three@0.160.1，MIT 许可证保存在 vendor；页面运行不依赖公网 CDN。

## 验收
真实 Chromium WebGL 2.0；12x20 状态派发/有限矩阵值、跳跃位移变化、真实拖拽侧转、暂停、选择记忆、390px 无溢出通过。240 项不是每个角色每个动作的人工美术验收。

## 未完成
毛绒仅为高粗糙度/sheen 材质近似，尚未建真实毛发；部分动作仍共用参数；不是最终雕刻/骨骼资产。生产帧率与显卡适配待测，不能据实验室效果声称业务性能验收通过。尚未接入真实 Agent 32 状态/员工账号配置，不部署、不调用付费供应商。

## 使用
在仓库目录运行 python -m http.server 13479 --bind 127.0.0.1，访问 /design/mascots/volume-v2/index.html。支持 WebGL 的浏览器可运行。附 comparison.png 是已打开检查的实际浏览器截图。

## 可复用设计提示
Naumi 彩色桌面伙伴，真实 3D 软胶玩具结构，饱满圆润体积，短肢体、嵌入亮面眼睛、柔和棚拍光和接触阴影，角色有不同个性；动作以身体重心、肢体与耳尾联动表达，不整张图晃动；避免平面描边和薄纸片。

## 2026-10-16 眼神跟随增强
眼睛从整组小幅平移升级为眼白 + 黑瞳 + 独立眼球关节；水平旋转最大约 48 度，垂直旋转约 25 度。全页面鼠标坐标按角色卡片归一化，眼神不再只在角色内部生效。指数阻尼平滑追踪，指针离开窗口和失焦后回正；暂停时冻结，睡眠不追踪；减弱动画时跳过弹性过渡。触摸仍保留拖拽侧转，不把手指伪装成悬停。保持既有拖拽、动作、选择和会话边界，本轮未接线上。

## 2026-10-16 默认正面
移除统一斜侧相机（x=2.8）与初始转向（-0.13rad），改为水平正面镜头 x=0、轻微俯角；初始 12 款统一待机，无自动转圈。眼球静止 yaw/pitch 都归零，保留鼠标驱动的明显跟随。拖动可查看侧面，松手使用指数阻尼回正；增加“正面”按钮，重置角色朝向、动作和眼神。材质、灯光与阴影继续呈现体积，不靠固定侧身制造厚度。仍仅为设计原型，未部署。
