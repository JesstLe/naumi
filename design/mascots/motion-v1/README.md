# Naumi 吉祥物动作概念 v1

12 款原创代码原生 SVG 概念，薰衣草紫、蜜桃、雾蓝、薄荷绿、珊瑚粉、湖蓝、奶油黄、丁香紫等共 12 套彩色方案。20 组动作：呼吸、探头、思考、执行、挥手、跳跃、转圈、伸懒腰、睡眠、唤醒、庆祝、出错、点头、摇头、害羞、晕乎、躲猫猫、鞠躬、摇摆舞、小碎步。

打开 index.html 即可离线交互，无依赖、无网络请求。支持本地伙伴选择记忆（不写生产用户配置）、鼠标目光跟随、指针拖动、键盘切换、单角色切换、全体动作、轮播、暂停、减弱动画。

角色动作性格通过独立轮廓、运动节奏和专属闲置动作区分；非 12 套完全独立的骨骼动画。此轮为动作设计原型，尚未接入生产 Agent 的真实状态，也未上线或替换原小球。后续可将已选角色接入既有 32 状态控制器。

构建：node build.cjs。comparison.svg 为静态造型概览，index.html 才是实际动画。静态 PNG 通过 sharp 渲染。

内置 image_gen 首次调用返回空内容，未产生可核验图片；此后按新增动作需求，制作可离线运行的 SVG/CSS 交互原型，未将空调用记为交付。

提示词方向：Naumi 原创多彩 AI 吉祥物，12 种不同轮廓（环绕球、糯米团、方块机器人、幽灵、猫、鹅卵石、圆角星、折纸 N、兔、小狗、六角恐龙、企鹅），高对比眼睛、浅色布局；颜色允许自由探索，不受黑白品牌限制；动作需支持眼睛跟随、思考、执行、探头、挥手、跳跃、转圈、伸懒腰、睡眠、唤醒、庆祝、出错。
