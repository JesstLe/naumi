# Naumi 非拟人伙伴形态实验 v3

## 本轮目标
回应“并非一定要胳膊脚丫、发挥想象力”：从自然现象、材料和形态的运动逻辑构造伙伴，而非把统一人形模板换皮或删掉手脚。

## 八款形态与运动
|形态|性格|结构|专属运动|
|---|---|---|---|
|云朵 PUFF|松弛|五个软云团，不设四肢|云团独立起伏、聚拢和散开|
|小伞 JELLY|安静|半球伞盖、细柔触须|伞盖收缩、触须延迟摆动|
|缎缎 RIBBON|灵动|双环立体绳结|环体扭转、横纵交替舒展|
|露露 DEW|专注|旋转曲面水滴|横向鼓起与纵向回弹|
|毯毯 MANTA|自由|软垫状飞毯|顶点驱动连续波浪、边缘轻掀|
|月牙 LUNA|内敛|有真实厚度的弯月|轻摇、蜷缩、缓慢伸展|
|花簇 BLOOM|热情|中心与七瓣花簇|花瓣独立折叠和舒展|
|星屑 COMET|敏捷|小星核与三条流光|拖尾错相波动，不用手脚动作|

## 已完成
- 8 种非拟人拓扑、8 组形态运动控制，12 个公共情绪/任务演示入口（呼吸、好奇、思考、执行、开心、不满、睡眠、唤醒、害羞、展开、旋转、律动）。
- 默认正面，眼白/独立瞳孔关节、显著鼠标跟随、平滑回中；拖动看侧面、松手回正。
- 暂停、轮播、键盘和仅浏览器本地角色选择。
- Three.js 真实 WebGL 网格、物理材质、主光与轮廓光、投影和接触阴影；使用 ./vendor 内固定的 MIT Three.js 0.160.1，无网络依赖。
- 暂停/睡眠/减弱动画处理保留；移动端双列。

## 边界与后续
这是独立设计原型，不是正式雕刻/最终骨骼资产。形态动作是真实参数/顶点变化，但物理挤压、流体和云聚散是艺术化动画，不是流体模拟。统一任务语义仍通过共享强度参数影响各形态，再由专属控制表达，不宣称 96 套完全独立动作。真实 Agent 状态、员工账号偏好、生产性能与显卡兼容尚未接入验收。保留 v1/v2 不覆盖，不发布线上，不调用收费供应商。

## 可复用设计提示
为创作团队设计非拟人桌面伙伴，不预设头身四肢；用云的聚散、水母的收伞、缎带的卷曲、水滴的形变、飞毯的波浪、月牙的摇摆、花瓣的开合、彗星的拖尾表达性格。保持饱满立体材质、默认正面、清晰眼神和轻柔接触阴影，不靠同一种小球换色。

## 2026-10-16 材质精修
- 8 个独立物理材质配置：云的哑光绒面、凝胶小伞、缎面丝带、湿润水滴、织纹飞毯、半釉月牙、柔绒花瓣与柔亮星核。绒面仅为 sheen + bump 近似，不是真实毛发。
- 两组确定性程序微纹理（细颗粒/交织），缎带启用各向异性高光；水母和水滴使用少量透明度，不宣称真实折射/次表面散射。
- 丝带从圆管改为具有宽度和薄厚的椭圆扫掠缎带；云从多球拼接改为 SDF 平滑并集的连续表面，减少硬拼缝。云聚散现在为连续外壳的整体形变，不再是五团独立位移。
- 眼睛分层为眼白、低饱和虹膜、黑瞳、主高光与小辅光，收小腮红。
- 调整棚拍环境灯板、主/补/轮廓光、材质曝光、软接触阴影；保持正面和明显眼神跟随。
- 新增“细看材质”双列大图，移动端细看单列；隐藏页停止继续绘制，减少预览重复开页资源消耗。
- 本轮只修改本地设计原型，不发布。T3 预览连续失联后改独立 headless Chromium/SwiftShader 核验，未连接日常浏览器。生产性能、真毛发/折射、最终美术验收与 Agent 接入仍未完成。
