# 独立参考图工作台

临时目标：47.105.59.142。后续作为103 `/batchshot` 的可迁移模块，本轮不发布103、不迁移其数据库。

## 已实现

- 原参考图工作台HTML/CSS及卡片、选择、框选、批量/逐卡提示词、推理指令、版本对比、标注（二次生成）、后台项目、ZIP交互保留；只有站点链接与独立管理员入口调整。
- FastAPI + SQLite持久任务队列，两并发；关闭浏览器不停止任务；重启后已有明确结果保持，未确认上游提交不自动重发。
- 登录/会话、账号素材隔离、越界路径/来源校验、图片内容校验、上传限制。
- 渠道配置/API Key加密保存；保存自动读取当前密钥 `/models`；生图和视觉推理模型显式选择；新任务冻结渠道配置；密钥不回显；失败不覆盖原配置。
- 生图 `/images/edits`（产品图+风格参考图）；推理 `/chat/completions`；二次生成只发当前结果+标注，不发产品图与同行图。

## 文件夹约定

选择一个产品文件夹。根目录图片、`产品图/`、`原图/`作为产品；`主图/`、`参考图/`作为主图风格参考；`详情图/`为详情；`SKU/`或用户填写的SKU子目录为SKU参考。卡片对应参考图，而不是每张产品图。其他子目录默认为主图参考；没有产品图明确报错，避免错用同行图片。

## 本地启动

Python 3.11+，`pip install -r requirements.txt`。部署环境设置 `WORKBENCH_DATA`、首次初始化的 `WORKBENCH_ADMIN_USER`/`WORKBENCH_ADMIN_PASSWORD`，以及固定 `WORKBENCH_VERSION`；凭据不提交。

```sh
uvicorn app:app --host 127.0.0.1 --port 17847
python -m pytest tests -q
```

渠道可由管理页配置，或部署时运行`bootstrap_channel.py`；后者读取环境`BOOTSTRAP_BASE/API_KEY/IMAGE_MODEL/TEXT_MODEL`，不写日志秘密。TDH复用已授权项目配置；本服务不依赖103运行进程。
